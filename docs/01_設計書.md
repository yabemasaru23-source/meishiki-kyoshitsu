---

## 1. この設計書の目的

「アプリで命式は出せた。でも、この表をどう読めばいいのかわからない」——
この状態から、**命式を自分の言葉で読み、相手に伝えられる**ところまで連れていく教材の設計図です。

- 兄弟の教材（`shikumi-keiei/`・`megane-keiei/`）と**同じ画面の作り**を使い回します
- 別サイト・別リポジトリで GitHub Pages に公開します
- 文章・例題・鑑定例は**すべて書き下ろし**です。占いの本やほかの教室の文章は転載しません
- 例に出す命式は**必ずアプリ（と検証用の第2エンジン）で出した結果**を使い、手で書きません
- ゴールは「鑑定ができるところまで」。開業・料金・集客は扱いません

### 2-2. アプリの「流派の決め」（教材もこれにそろえる）

`verify/README.md` で確定している約束を、教材でもそのまま使います。

- 年・月の切りかわりは**節入り**（立春など）で決める。お正月や1日ではない
- 節入りからの日数は暦日で数え、節入り当日を1日目とする
- 蔵干は四柱すべてに「節入りからの日数」を当てて決める
- 節入り当日生まれは流派で結果が変わることがある（教材では「先生に確かめるポイント」として一度だけ触れる）

### 2-3. 初心者がつまずくところ（教材で解決すること）

| # | つまずき | 教材での解決 |
|---|---|---|
| 1 | 表に漢字が多すぎて、どこから見ればいいかわからない | **「日干から見る」**と最初に決め、読む順番を7ステップに固定する |
| 2 | 1月・2月生まれなのに年柱が前の年になっていて、アプリが間違っていると思う | 第6章で「年の始まりは立春」を先に教える |
| 3 | 通変星が10個あって覚えられない | 「日干との関係（5種類）×陰陽（2つ）」のしくみで覚える。暗記させない |
| 4 | 星ひとつの意味はわかっても、組み合わせると読めない | 第18章の「読解シート」で、星をつないで1つの人物像にする練習をする |
| 5 | 天中殺・五行の偏りを「悪いもの」と思って、こわい伝え方をしてしまう | 「良い悪いではなく、くせと使い方」で一貫して教える。第21章で伝え方の約束を決める |
| 6 | アプリの鑑定文を読み上げるだけになる | 第19章で「アプリの文章 → 相手の事実を聞く → 自分の言葉」に直す練習をする |

## 3. 作り方の基本方針（5原則）

1. **暗記させない、しくみで覚える**：五行の関係がわかれば、通変星も十二運星も「なぜそうなるか」で理解できる順番にする
2. **毎章アプリを開く**：各章に「アプリで見てみよう」を入れ、自分の命式の該当マスを確認させる
3. **1章＝同じ型**：「ひよりの疑問 → たとえ話 → しくみ → アプリで見る → 練習問題 → まとめ・チェック」でそろえる
4. **最後に1枚の鑑定メモになる**：各章で書いた「わたしの命式ノート」が、第18章の読解シートに自動で集まる
5. **こわがらせない占い**：どの章でも「良い・悪い」ではなく「持ち味・くせ・使い方」で語る

## 5. 1章の型

| ブロック | 中身 |
|---|---|
| ひよりの疑問 | 学ぶ人「ひより」が、その章でつまずくポイントを口にする |
| たとえ話 | 案内役が、日常のものにたとえて説明する（例：十干＝10人の主人公、命式＝4部屋の家） |
| しくみ | 図と表で考え方を説明する。暗記ではなく「なぜそうなるか」 |
| アプリで見てみよう | どのタブの、どのマスを見ればいいかを、画面の図つきで示す |
| 練習問題 | 架空の人物の命式で3〜10問。答え合わせつき |
| わたしの命式ノート | 自分の命式について書きこむ（ブラウザに保存、第18章に集まる） |
| まとめ・チェック | 3行まとめ＋理解チェック3問 |
