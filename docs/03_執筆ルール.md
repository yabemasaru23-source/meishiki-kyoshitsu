# 執筆ルール（全章共通）

この教材「はじめての命式 ― 本当の自分を知る陰陽五行」の章を書くときのルールです。
**見本：`content/chapters/02_五行.md` と `content/chapters/11_通変星のしくみ.md`。書く前に必ず両方を全部読み、同じ型・同じ口調・同じ細かさで書くこと。**

## 0. 読む資料
- `docs/01_設計書.md` … 全体構成（章のねらい・完成物・目安時間）
- `content/example/people.md` … 登場人物と、検証ずみの命式（ここから写す）
- `README.md` … 本文の書き方（吹き出し・クイズ・五行の色）
- 兄弟サイトの入力欄の書き方：`../../shikumi-keiei/README.md` の「入力欄（ワーク）の書き方」
- 命式アプリ本体 `../index.html`（約37万字。**全部は読まない**。Grep で必要な関数・文言だけ読む）
- 検証エンジン `../verify/independent-engine.js`、流派の決め `../verify/README.md`

## 1. 読者と口調
- 読者は**陰陽五行をまったく知らない初心者**。小学校高学年でも読める言葉で。むずかしい漢字にはふりがなを（　）で
- 地の文は「です・ます」。まあ先生は「〜よ」「〜わ」「〜ね」のやわらかい口調。ひよりは素直で、思ったことを口にする
- 天中殺・五行の偏り・凶とされる星などは、**「良い悪い」ではなく「持ち味・くせ・使い方」**で語る。こわがらせない
- 健康は「昔の考え方で見た、気をつけるといい場所」であって診断ではない。病気・死・事故・離婚などを断定しない
- 占いの本・他の教室・アプリの鑑定文を**転載しない**。すべて書き下ろし。アプリの文言を引用するのは見出し名など短いものだけ

## 2. 章の型（見出しは必ずこの番号つき）
```
---
id: "NN"
title: "（chapters.json と同じ）"
cover: "chNN-cover.svg"
subtitle: "ひとことで言うと…"
stage: "陰陽五行のきほん" | "命式の読み方" | "鑑定の実践"
required: true
minutes: （設計書の目安）
output: "この章でできあがるもの"
---
## ① この章でできるようになること
## ② ひよりの疑問          … 🙋ひより → 🐱まあ先生 の会話
## ③ たとえ話：〜          … 日常のたとえ。表や図（![説明](assets/img/chNN-xxx.svg)）
## ④ しくみ                … ### 1. 〜 のように小見出し。表・💡ヒント・ひよりの例
## ⑤ アプリで見てみよう    … > 📱 で、どのタブのどのマスを見るか手順で
## ⑥ 練習問題              … ```work type: quiz（6〜10問、explain つき）
## ⑦ わたしの命式ノート    … 自分の命式で書く入力欄（記入例＝ひよりさん）
## ⑧ まとめ・セルフチェック … ### 3行まとめ ／ ### セルフチェック（- [ ] を5つ）
## ⑨ 次の章へ
## ⑩ 講師ガイド            … ねらい／時間配分の表／問いかけの例／よくあるつまずきの表
```
- 吹き出し：`> 🐱 **まあ先生**` ／ `> 🙋 **ひより**`（名前のあとで改行して本文）／ `> 💡 **見出し**` ／ `> 📱 **アプリで見てみよう：〇〇タブ**`
- 五行の色：`<span class="g-moku">木</span>`（g-ka 火／g-do 土／g-kin 金／g-sui 水）
- 命式の表は、アプリと同じく**右から年柱・月柱・日柱・時柱**（左から 時柱｜日柱｜月柱｜年柱）。`<div class="meishiki-box">` で囲む（前後に空行）
- アプリへのリンクは `[命式アプリ](https://qmw.co.jp/meishiki/)`
- 長い早見表は `<details><summary>…</summary>`（前後に空行）で折りたたむ

## 3. 入力欄（```work）の id のきまり
- id は `NN.` で始める（NN＝章番号2けた）
- **「わたしの命式ノート」の入力欄は、必ず `NN.me.〇〇` の形**にする（`NN.me` だけの id は作らない。第0章の `00.me` だけ例外）
  - 第18章の読解シートが `source: [08.me, 09.me, …]` で、その章の `NN.me.*` をまとめて表示するため
- 練習問題は `NN.quiz`（2つ以上なら `NN.quiz1`, `NN.quiz2`）
- 記入例（example）は**ひよりさん**の命式で書く。ラベルは自動で「記入例（ひよりさんの場合）」になる
- 使える type：text / textarea / select / checklist / table（rows で行見出し固定）/ form（fields）/ quiz / display（前の章の答えを表示）

## 4. 命式・数字の正確さ（いちばん大事）
- 命式は**手で書かない**。`content/example/people.md` から写す
- 新しい人物・日付が必要なら、スクラッチの計算スクリプトで本体と検証エンジンの**両方**を計算し、「照合:一致」のものだけ使う：
  `node C:/Users/yabem/AppData/Local/Temp/claude/C--Users-yabem-OneDrive---------------------/98f343eb-e4a5-4e75-976f-8529107526a3/scratchpad/mei.js 1998-5-14-14`（年-月-日-時。時刻なしは 1966-7-3）
  新しく使った人物は people.md に追記してよい
- 通変星・十二運星・天中殺・五行の数など、**クイズの答えも必ず計算結果で確かめる**
- アプリの表示（タブ名・段の名前・並び・数字の出し方）は、`../index.html` を Grep して**実物にそろえる**。想像で書かない
- 流派の決め（節入り・蔵干の日数・エネルギーの数値など）は、アプリと `verify/README.md` に従う

## 5. 図（SVG）
- 置き場所 `assets/img/`。扉絵 `chNN-cover.svg`（viewBox 0 0 800 320）＋本文の図 1〜2枚
- 色は CSS 変数＋予備の色：`var(--ink, #26221d)` `var(--ink-soft, #6a6157)` `var(--surface, #fffdf8)` `var(--sunk, #efe8dc)` `var(--sun, #d9a441)` `var(--sun-soft, #f6ead0)` `var(--warm, #c03430)` `var(--moku, #2d7a4a)` `var(--ka, #c03430)` `var(--do, #a87018)` `var(--kin, #6b7584)` `var(--sui, #2854a0)`
- 文字は `font-family="Zen Maru Gothic, sans-serif"`（大きな漢字は `Zen Old Mincho, serif`）。最小12px。**文字どうし・矢印と箱が重ならないこと**（座標を計算して確かめる）
- `role="img"` と、図の中身を文章で説明した `aria-label` をつける
- 見本：`assets/img/ch02-five.svg` `assets/img/ch11-wheel.svg`
