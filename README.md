# はじめての命式 ― 本当の自分を知る陰陽五行

あなたは、まだ本当の自分を知らない。
陰陽五行をまったく知らない人が、命式アプリ（https://qmw.co.jp/meishiki/）を使って命式の読み方を一歩ずつ学び、
自分の言葉で鑑定ができるようになる学習サイトです。

- 全23章（★必修17章）。第1部 きほん／第2部 命式の読み方／第3部 鑑定の実践
- 入力した内容は、見ている人のブラウザの中だけに自動保存されます（サーバーには送られません）

## フォルダ構成

```
meishiki-kyoshitsu/
├─ index.html
├─ assets/          app.css・app.js（兄弟サイトと同じ仕組み＋クイズ）、img/ 挿絵
├─ content/
│   ├─ chapters.json   章の一覧（章を追加したら "file" にファイル名を書く）
│   ├─ chapters/       各章の本文（Markdown）
│   └─ example/        登場人物と例の命式（アプリと検証エンジンで一致を確認ずみ）
└─ docs/            設計書
```

## 本文の書き方（この教材で追加したもの）

| 書き方 | 表示 |
|---|---|
| `> 🐱 **まあ先生**` で始まる引用 | まあ先生の吹き出し |
| `> 🙋 **ひより**` で始まる引用 | ひよりの吹き出し |
| `> 💡` で始まる引用 | ヒント |
| `> 📱` で始まる引用 | アプリで見てみよう |
| ` ```work ` の `type: quiz` | 選択式クイズ（`questions:` に `q`・`options`・`answer`・`explain`） |
| （自動） | 十干・十二支・専門用語に、ふりがなが自動でつく。画面上の「ふりがな」ボタンで消せる。読みの一覧は app.js の KANSHI・TERMS |
| `<span class="g-moku">木</span>` など | 五行の色（g-moku／g-ka／g-do／g-kin／g-sui） |

そのほかの入力欄の書き方は、兄弟サイト `shikumi-keiei/README.md` と同じです。

**例の命式は手で書かないこと。** `content/example/people.md` から写すか、
`../index.html` と `../verify/independent-engine.js` の両方で計算して一致したものだけを使います。

## パソコンで試しに見るには

```bash
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。

## 著作権について

本教材の文章・設問・例は、すべてオリジナルで書き下ろしたものです。
登場する人物（まあ先生・ひより・そうた・ふみえ・れん）と生年月日は架空であり、実在の人物とは関係ありません。
