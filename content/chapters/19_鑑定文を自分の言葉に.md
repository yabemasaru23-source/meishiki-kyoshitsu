## ① この章でできるようになること

- アプリの「鑑定」タブの各ブロックが、**命式のどの柱・どの段・どの星から出ているか**を言える
- アプリの文章をそのまま読み上げてはいけない理由を、3つ説明できる
- 鑑定文を「**根拠にさかのぼる → 事実を聞く → 自分の言葉に言い直す**」の3つの手順で使えるようになる
- こわがらせない・決めつけない・行動につなげる言い方に、自分で書き直せる

## ③ たとえ話：カフェのマニュアルと、常連さんへのひとこと

ひよりさんのカフェには、接客のマニュアルがあります。
「いらっしゃいませ。ご注文がお決まりでしたら、お知らせください」

これはまちがっていません。だれに言っても失礼にならない、よくできた文です。
でも、毎朝来る常連さんに、ひよりさんはこう言います。

> 「おはようございます。今日は冷えますね。いつものカフェラテ、ホットにしますか？」

| | マニュアルの文 | ひよりさんのひとこと |
|---|---|---|
| だれに向けた文？ | お客さん「みんな」 | 目の前の「この人」 |
| もとになっているもの | お店のきまり | お店のきまり＋その人のこと（いつもの注文・今日の天気） |
| 相手の気持ち | 失礼ではない | 「わたしのことを見てくれている」 |

アプリの鑑定文は、**このマニュアルの文**です。命式のある星を持つ人「みんな」に向けて書かれています。
鑑定する人は、マニュアルを知ったうえで、**目の前の人に合わせたひとこと**に言い直します。

## ④ しくみ

### 1. 鑑定タブの文章は、命式のどこから出ているか（対応表）

鑑定タブには、上から順に13のブロックがあります。アプリのしくみを調べて、**それぞれの文章がどこから作られているか**を表にしました。
右の列は、ひよりさんの命式で実際に使われている材料です。

| 鑑定タブの見出し | 命式のどこから出ているか | ひよりさんの場合 |
|---|---|---|
| 日干 — 本質の気質 | **日干だけ**（10種類） | 辛 |
| 性格分析 — 長所と課題 | **日干だけ** | 辛 |
| パートナー傾向 | **日干だけ** | 辛 |
| 家族関係 | 親との縁＝**年柱の通変星**／配偶者・パートナーとの縁＝**日柱の十二運星**／生日中殺があれば一文が加わる／子供との縁＝**時柱の通変星**と、命式全体（通変星・蔵干通変星）に**食神・傷官があるか** | 年柱 印綬／日柱 建禄／生日中殺あり／時柱 偏財（食神・傷官はなし） |
| 意思決定プロセス — 三つの顔 | 表の顔＝**年柱の通変星**／内なる欲求＝**月柱の通変星**／意思決定スタイル＝**日干の五行**（5種類） | 印綬／偏官／金 |
| 向いている職業 | 職業のリストと説明＝**日干の五行**／補足＝**月柱の通変星**と**日干** | 金／偏官／辛 |
| 五行バランス詳細 | **五行の数**。0の五行があればその説明、3つ以上の五行があればその説明。どちらもなければ「そろっている」の文 | 水0（いちばん多くても2なので、「多い」の説明は出ない） |
| 通変星 — 各柱の働き | **年柱・月柱・時柱の通変星**を1つずつ（日柱は「—」なので出ない） | 印綬・偏官・偏財 |
| 十二運星 — エネルギーの質 | **4本の柱の十二運星**とエネルギーの数 | 胎3・死2・建禄11・衰8 |
| 天中殺 — 充電の季節 | **日柱からの天中殺**（6種類）と、今年からさがした天中殺の年 | 子丑／次は2032年・2033年 |
| 幼少期〜青年期（〜29歳頃）の傾向 | **年柱の通変星と十二運星** | 印綬・胎 |
| 大運 — 10年サイクル | 年柱の天干の陰陽×**性別**で順行・逆行／節入りとの日数ではじまりの年齢／**月柱の干支**から10年ごとの干支 | 逆行・3歳から。いまは23歳〜の甲寅 |
| 年運 — 直近の流れと展望 | **その年の干支**。上の字を日干から見た通変星で文章、下の字で十二運星、日柱からの天中殺にあたれば「天中殺」の印 | 2026年 丙午：正官・病 |

> 💡 **表からわかる、3つの大事なこと**
> 1. **はじめの3つのブロックは、日干だけで決まっています。** 日干が同じ人（およそ10人に1人）には、まったく同じ文章が出ます
> 2. **蔵干通変星は、ほとんど使われていません。** 出てくるのは「子供との縁」で食神・傷官を数えるところだけ。第18章で読んだ「内側の本音」は、**あなたが足す部分**です
> 3. **年柱からの天中殺と生月中殺は、鑑定タブには出てきません。** 命式タブの表の下で見ます

> 🐱 **まあ先生**
> もうひとつ。アプリは年柱を「表の顔（他者からの印象）」という見出しでも使っているわね。
> この教材の第9章では、年柱は「ルーツ・若いころ」だったでしょう？ 柱の意味づけは、見方によって少しずつちがうの。
> でも、**材料は同じ「年柱の印綬」**。根拠にさかのぼれば、どちらの見出しにふり回されることもなく、自分の読みで話せるわ。

> 💡 **年運の「年」について**
> 年運のブロックは、2026年、2027年……と西暦の年ごとに干支をならべています。
> 第6章で学んだとおり、干支の1年は**立春から**切りかわります。1月や2月のはじめの話をするときは、「まだ前の年の干支の季節」だと覚えておきましょう。

### 2. なぜ、読み上げるだけではいけないのか

| 理由 | どういうことか | ひよりさんの例 |
|---|---|---|
| ① **命式の一部分しか見ていない** | ほとんどのブロックは、1つの段・1つの星から作られている。星どうしの組み合わせ（第18章の「重なり」「表と裏」）は読んでいない | 日干のブロックは、辛の人みんなと同じ文。ひよりさんの「劫財の負けずぎらい」は、どこにも出てこない |
| ② **言い切りの文が多い** | 「〜で育ちました」「〜の傾向があります」と、その人の事実を知らないまま言い切っている | あかりちゃんの「うち、ぜんぜんそんなことないけど」 |
| ③ **こわく聞こえる言葉が混ざる** | 天中殺の「避けること」の一覧や、からだの話など、そのまま読むと不安にさせる言葉がある | 天中殺の年の一覧を読み上げると、「その2年は何もできないの？」と思わせてしまう |

> 🐱 **まあ先生**
> アプリの文章が悪いわけではないのよ。「この星の人には、こういうことが多い」という、**よくできたマニュアル**なの。
> 問題は、マニュアルを**目の前の人の事実**だと思って読んでしまうこと。そこに、鑑定する人の出番があるのよ。

### 3. 鑑定文の使い方 ― 3つの手順

**手順1　根拠にさかのぼる**
その文章が、命式の**どの柱の、どの段の、どの星**から出ているかを、④の1の表で確かめます。
根拠がわかれば、第12章〜第14章で学んだ「その星の持ち味とくせ」に戻って、別の言い方を探せます。

**手順2　事実を聞いて確かめる**
言い切る前に、相手に聞きます。「**こんなこと、ありますか？**」
当たったら、相手の言葉を使って話を広げます。当たらなかったら、**相手の話のほうが正しい**。手順1にもどって、同じ星の別の読み方を探します。

**手順3　自分の言葉に言い直す（3つの約束）**

| 約束 | やりかた |
|---|---|
| **こわがらせない** | 「弱い」「足りない」「注意」「避ける」を、「静かに出る」「まだ使っていない引き出し」「〜すると力が出やすい」「〜の前に準備を」に言いかえる |
| **決めつけない** | 「〜です」「〜で育ちました」を、「〜かもしれません」「〜のように見えます。思い当たりますか？」にする |
| **行動につなげる** | 最後に「だから、こうしてみては？」をひとつ。小さくて、明日からできることがいい |

### 4. 言い直しの例（before → after）

ここでは、アプリの文章ではなく、**よくある鑑定文の言い方を、この教材で作った架空の例**で練習します。

**例1　家族関係（年柱の星から）**

| | |
|---|---|
| before | 「あなたは、礼儀にきびしい家で育ちました。」 |
| 根拠 | 年柱の通変星が正官 |
| 聞く | 「子どものころ、あいさつや約束を大事にする大人が、近くにいましたか？」 |
| after | 「若いころに、きちんとすることの大切さを教えてくれた人がいたのかもしれません。いまの誠実さは、そこから来ているように見えます。」 |

> 💡 **当たらなかったときは**
> 「いなかったなあ」と言われたら、「それなら、その誠実さは**自分で身につけてきた**ものですね」と返せます。
> 星の持ち味（正官＝きちんと・誠実）は同じでも、**どこでそれを身につけたか**は、その人の人生が決めることです。

**例2　五行バランス（0の五行）**

| | |
|---|---|
| before | 「火がありません。情熱が足りず、心臓に気をつけてください。」 |
| 根拠 | 五行の数で火が0 |
| 聞く | 「気持ちが盛り上がるまでに、少し時間がかかるほうですか？」 |
| after | 「火の引き出しが、まだ空いている命式です。パッと燃えるより、落ちついて進めるのが得意なのかも。明るい人と過ごしたり、楽しいことの予定を入れたりすると、火の気をもらえますよ。」 |

> 🐱 **まあ先生**
> からだの話は、昔の考え方で見た「気をつけるといい場所」。**お医者さんの代わりにはならない**から、鑑定では言わないか、言うなら「昔の考え方では」とそえてね（第2章・第21章）。

**例3　天中殺**

| | |
|---|---|
| before | 「再来年から天中殺です。転職や引っ越しは避けてください。」 |
| 根拠 | 日柱からの天中殺と、その年の干支の下の字 |
| 聞く | 「再来年あたりに、なにか大きな予定や、考えていることはありますか？」 |
| after | 「再来年からの2年は、天中殺という充電の季節です。大きな決めごとは、その前の年までに準備しておくと気持ちが楽ですよ。2年のあいだは、学び直しや片づけに向いています。」 |

**例4　十二運星（エネルギーが小さい柱）**

| | |
|---|---|
| before | 「月柱が絶なので、仕事運が弱いです。」 |
| 根拠 | 月柱の十二運星が絶（エネルギー1） |
| 聞く | 「仕事で、まわりがおどろくような新しいやり方を思いつくことはありますか？」 |
| after | 「仕事の場では、力で押すより、まったく新しい発想で動くタイプに見えます。決まった型にはまるより、自分で工夫できる場所で光りそうです。」 |

**例5　向いている職業**

| | |
|---|---|
| before | 「あなたに向いている職業は、会計の仕事です。」 |
| 根拠 | 日干の五行（金）。**同じ五行の人みんな**に同じリストが出る |
| 聞く | 「いまのお仕事で、『ここは自分が得意だな』と思うのは、どんなところですか？」 |
| after | 「正確さや、決まりを守る力が生きる場面で光る人です。いまのお仕事でいうと、さっき話してくれた在庫の管理が、まさにそれですね。」 |

**例6　年運**

| | |
|---|---|
| before | 「今年は偏官の年。プレッシャーが大きく、たいへんな年です。」 |
| 根拠 | 今年の干支の上の字を、日干から見ると偏官 |
| 聞く | 「最近、新しい役目や、まかされていることはありますか？」 |
| after | 「今年は、きたえてくれる星がめぐってくる年です。新しい役目をまかされたら、成長のチャンス。がんばるぶん、休む予定も先にカレンダーに入れておきましょう。」 |

### 5. 言いかえ早見表

| アプリによくある言い方 | 鑑定での言い方 |
|---|---|
| 〜です（言い切り） | 〜かもしれません。思い当たりますか？ |
| 〜で育ちました | 若いころに、〜に縁があったように見えます |
| 〜が弱い・足りない | 〜は静かに出る力／まだ使っていない引き出し |
| 〜に注意 | 〜すると、もっと力が出やすい |
| 〜は避けてください | 〜の前に準備しておくと安心です |
| 向いている職業は〇〇 | 〇〇のような場面で光りやすい。いまの仕事なら〜のところ |
| 「運が悪い」「凶」 | **使わない**。持ち味・くせ・季節で言いかえる |

### 6. ひよりさんの実演 ― 自分の鑑定タブを3つ書き直す

ひよりさんが、自分の鑑定タブから3つのブロックを選んで、書き直してみました。

**① 日干 — 本質の気質**

- 根拠：日干の**辛**（陰の金）。辛の人みんなに同じ文が出る
- アプリの文の要点：宝石のたとえで、美意識、繊細さ、品質へのこだわりを書いている
- 事実（自分に聞いた）：ラテアートの形がそろわないと、お客さんが気にしていなくても作り直したくなる
- 自分の言葉：「わたしは、細かいところの『きれい』に気がつく人。その目は、お店の品質を守る力になる。ただ、全部を完ぺきにしようとすると疲れるので、『ここだけはゆずらない』を1つ決めておく」

**② 通変星 — 各柱の働き（月柱の偏官）**

- 根拠：**月柱の通変星**が偏官
- アプリの文の要点：規律とまとめ役の星。自分にも人にも高い基準を求めるので、プレッシャーも大きい、という内容
- 事実：忙しい日にシフトのまとめ役をまかされる。新人さんに強く言いすぎて、あとで反省したことがある
- 自分の言葉：「いざというとき『まかせて』と言えるのが、わたしの強み。基準が高いぶん、人にも同じことを求めそうになったら、ひと呼吸おいて『どうしたらできそう？』と聞いてみる」（第18章で読んだ、内側の劫財＝「仲間と一緒にやりとげたい」気持ちも足しました）

**③ 天中殺 — 充電の季節**

- 根拠：**日柱からの天中殺**が子丑。今年からさがした次の天中殺の年は2032年・2033年
- アプリの文の要点：冬（子・丑）の天中殺。毎年12月上旬〜2月上旬ごろの月と、子・丑の日がそれにあたる。その時期に避けることと、向いていることの一覧
- 事実：冬は毎年なんとなく疲れやすく、年末年始にあれこれ予定を入れて、くたくたになる
- 自分の言葉：「冬は、わたしの充電の季節。12月〜1月は新しい予定をつめこみすぎず、ふり返りと学びの時間にする。2032年からの2年に向けて、それまでにやりたいことを形にしておく」

> 🙋 **ひより**
> 書き直してみると、アプリの文が「まちがい」じゃなくて、「話のきっかけ」だったんだってわかりました。
> 根拠がわかってると、あかりちゃんに「ちがう」って言われても、あわてずに「じゃあ、どんな感じ？」って聞けそうです。

> 🐱 **まあ先生**
> そう。「ちがう」は失敗じゃなくて、**相手が自分のことを話してくれたしるし**。そこからが、本当の鑑定よ。

## ⑤ アプリで見てみよう

> 📱 **アプリで見てみよう：鑑定タブ**
> 1. [命式アプリ](https://qmw.co.jp/meishiki/)で自分の命式を出します。性別の欄は最初「男性」になっているので、**自分の性別を選びなおして**おきましょう。大運の向きとはじまりの年齢は、性別で変わります（「回答しない」を選ぶと、大運の向きと年齢は出ません）
> 2. 結果の上のタブから「**鑑　定**」を押します
> 3. 上から13のブロックの見出しを順に見ていき、④の1の表で「**どこから出ているか**」を指でたどります
> 4. 気になったブロックがあったら、「**命　式**」タブにもどって、その根拠のマス（たとえば家族関係なら、年柱の通変星と日柱の十二運星）を見つけます
> 5. 第18章で書いた自分の人物像と、アプリの文章をくらべてみましょう。**同じところ**と**ちがうところ**はどこですか？

> 💡 **「今年」は見る日によって変わる**
> 天中殺の「次の天中殺年」や、年運の「今年・来年」は、アプリを開いた日の年をもとに出ています。
> この教材の例は、2026年に見た場合です。

### 3行まとめ

1. 鑑定タブの文章は、命式の**1つの段・1つの星**から作られた「みんな向けのマニュアル」。とくに最初の3ブロックは日干だけで決まる

## ⑩ 講師ガイド

### この回のねらい
受講者が、アプリの鑑定文を「当たる・当たらない」で見るのをやめ、**どの星から出た文か**をたどれるようになること。そのうえで、相手の事実を聞き、自分の言葉で言い直す流れを体験してもらう。「アプリが言っているから」を言いわけにせず、**伝える言葉の責任は鑑定する人にある**という感覚を持ってもらう。

### 時間配分（60分の例）

| 時間 | 内容 | ポイント |
|---|---|---|
| 0:00〜0:05 | チェックイン | 「アプリの鑑定文を読んで、ドキッとしたことはありますか？」 |
| 0:05〜0:12 | お話：②③ | カフェのマニュアルのたとえ。「マニュアルの文はまちがいではない」を先に言っておく |
| 0:12〜0:25 | ④の1〜2：対応表 | 自分の鑑定タブを開き、講師と一緒に上から見出しをたどる。「日干だけで決まるブロック」に印をつける |
| 0:25〜0:35 | ④の3〜5：言い直し | 例1〜6のうち2つを、before だけ見せて受講者に言い直してもらってから after を見せる |
| 0:35〜0:50 | ワーク：書き直しカード | 2人組で、1人が相手の鑑定タブから1つ選んで言い直し、相手が「事実」を答える役 |
| 0:50〜0:55 | 練習問題 | 根拠クイズで表の確認 |
| 0:55〜1:00 | まとめ | 「ちがう、と言われたら？」を全員で答えて終わる |

### 問いかけの例
- 「日干が同じ人どうしで、鑑定タブの最初の3つのブロックをくらべてみましょう。どうなっていますか？」
- 「アプリの文を読んで『ちがう』と思ったところ。その根拠の星には、ほかにどんな読み方がありましたか？」
- 「あなたが言われてうれしいのは、before と after のどちらですか？ それはなぜでしょう？」

### よくあるつまずき

| つまずき | 対応 |
|---|---|
| アプリの文を「正解」だと思い、自分の読みとちがうと不安になる | 対応表で「1つの段から作られた文」だと確認する。組み合わせを読んでいるのは自分のほうだと伝える |
| 「アプリの文の要点」で、文章をそのまま写してしまう | 「見ないで、となりの人に説明するつもりで」と声をかける。写すと、自分の言葉に直す練習にならない |
| 言い直すと、ぼんやりして何も言っていない文になる | 「行動につなげる」の約束をくり返す。最後に「だから、〜してみては？」を必ず入れる |
| 「事実」を聞くのが、当てものクイズのようになる | 当たったかどうかではなく、相手の話を聞くための質問だと伝える。「当たっていますか？」より「どんなときに、そう感じますか？」 |
| 天中殺や五行の0のブロックを、こわがったまま書く | ⑤の言いかえ早見表と、第15章・第16章の「くせと使い方」「充電の季節」に戻る。こわい言葉は根拠にさかのぼると、ほとんどが「季節」や「引き出し」の話になる |
| 年柱の意味が、アプリの見出し（表の顔）と教材（ルーツ・若いころ）でちがって混乱する | 材料（年柱の星）は同じで、意味づけの角度がちがうだけと説明する。根拠にさかのぼれば、どちらの見出しでも自分の読みで話せる |
