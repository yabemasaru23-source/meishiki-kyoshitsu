## ① この章でできるようになること

- 占いで**答えてはいけない・答えきれない相談**（命にかかわる気持ち・病気・暴力・借金・法律の争い・犯罪被害・強い依存）を見分けられる
- そのときの対応の型「**受けとめる → 確かめる → つなぐ → 鑑定は無理に続けない → 自分を守る**」を使える
- 全国の**相談窓口**（電話番号・受付時間）を知り、**自分の地域のつなぎ先**を調べてメモできる
- 相手をこわがらせずに、**占い師としての役目の範囲**を伝える言いかえができる
- 相談を受ける自分自身を守るための、**境界線と約束**を持てる

> 🐱 **まあ先生**
> 鑑定をしていると、いつか必ず、**占いでは答えられない相談**に出会うわ。
> そのとき大切なのは、命式で答えをさがすことではないの。**目の前の人の話を受けとめて、その人を助けられる人のところへ、ちゃんとつなぐ**こと。
> この章は、教材の中でいちばん「命式を使わない」章よ。でも、占い師として活動するなら、いちばん大事な章かもしれないわ。

> 💡 **この章の情報について**
> 相談窓口の電話番号・受付時間は、**2026年11月時点**で、厚生労働省・内閣府・こども家庭庁・消費者庁・警察庁・法テラス・各窓口の公式サイトで確かめたものです。
> 番号や時間は**変わることがあります**。使う前に、必ず**それぞれの公式サイトで最新の情報**を確かめてください。

## ③ たとえ話：山小屋の人

登山道のとちゅうにある、**山小屋の人**を思いうかべてください。

山小屋の人は、登山客にお茶を出し、道の様子や天気の話をします。山のことにはくわしい人です。
でも、ある登山客が**足をひどくけが**して入ってきたら、どうするでしょう。

| 山小屋の人がすること | 鑑定でいうと | 型 |
|---|---|---|
| 「たいへんでしたね、ここにすわってください」と、まず休ませる | 話をさえぎらず、気持ちを受けとめる | ① **受けとめる** |
| 「歩けますか？ 血は止まっていますか？」と、けがの具合を確かめる | 命の危険があるかを確かめる | ② **確かめる** |
| 自分で手術はしない。救助隊やふもとの病院に連絡する | 占いで答えず、専門の窓口につなぐ。一緒に番号を調べる | ③ **つなぐ** |
| 「今日は山頂は目指さず、下りましょう」と言う | 鑑定は無理に続けない | ④ **続けない** |
| 救助のあと、自分も休む。ひとりでかかえこまない | 境界線を守り、燃え尽きない | ⑤ **自分を守る** |

## ④ しくみ

### 1. 占いで答えてはいけない・答えきれない相談

次のような相談は、**命式で答えを出してはいけません**。どれも、専門の人の力が必要な相談です。

| 相談の種類 | 言葉の例 | なぜ占いで答えないか | つなぎ先（④の4） |
|---|---|---|---|
| **命にかかわる気持ち** | 「死にたい」「いなくなりたい」「消えてしまいたい」 | 命を守ることが最優先。運勢の話は、その気持ちをとりのこしてしまう | 緊急なら110・119。いのちの電話、#いのちSOS、よりそいホットライン など |
| **病気・妊娠・服薬** | 「この薬をやめてもいい？」「手術の日はいつがいい？」「赤ちゃんはできる？」 | 診断や治療の判断は、お医者さんの仕事（第21章の約束②） | かかりつけのお医者さん・薬剤師。こころの不調なら、こころの健康相談統一ダイヤル |
| **暴力（DV・虐待）** | 「夫にたたかれる」「親がこわくて家に帰れない」「子どもに手をあげてしまう」 | 安全の確保が最優先。占いで「縁」や「時期」の話にしない | 緊急なら110。DV相談ナビ #8008、DV相談＋、189 |
| **借金・お金のトラブル** | 「借金が返せない」「高い契約をさせられた」 | 解決には、法律やお金の手続きが必要 | 消費者ホットライン188、法テラス |
| **法律の争い** | 「離婚の裁判で勝てる？」「相続でもめている」 | 勝ち負けや手続きは、弁護士などの仕事 | 法テラス、弁護士 |
| **犯罪被害** | 「ストーカーにつけられている」「だまされてお金をとられた」 | 安全の確保と、警察への相談が必要 | 緊急なら110。#9110、法テラスの犯罪被害者支援ダイヤル |
| **強い依存** | 「毎日鑑定してください」「先生が決めてくれないと何もできない」 | 占いが、本人の「自分で決める力」をうばってしまう | 鑑定の回数を区切る。気持ちのつらさが強ければ、こころの相談先へ |

> 🐱 **まあ先生**
> 「答えない」は、「**話を聞かない**」ではないのよ。
> 話はしっかり聞く。気持ちは受けとめる。でも、**その問題の答えを、命式で出さない**。
> 答えを出すのは、その分野の専門家。占い師は、そこまでの**道案内**をするの。

### 2. 対応の型 ― 5つのステップ

むずかしい相談が出てきたら、次の5つのステップで動きます。厚生労働省は、悩んでいる人に気づき、声をかけ、話を聞いて、必要な支援につなげ、見守る人を「**ゲートキーパー**」と呼び、特別な資格はなくてもだれでもなれる、と案内しています。この型は、その考え方を鑑定の場にあてはめたものです。

**① 話をさえぎらず、受けとめる**

- 相手の言葉を、**否定しない・はげまさない・説教しない**
- 「そんなこと言わないで」「がんばれば大丈夫」「みんなつらいんだから」は、言わない
- 相手の言葉を**くり返して**、つらさを受けとめる：「**いないほうがいい、と思うくらい、いまつらいんですね**」
- 話してくれたことに**お礼を言う**：「話してくださって、ありがとうございます」

**② 命の危険があるか、確かめる**

- 命にかかわる言葉が出たら、思い切って確かめる：「**死にたい、と思うくらいつらいですか？**」
- はっきり聞くのがむずかしければ、「**いなくなりたい、と思うことがありますか？**」のように聞いてもかまいません
- **いますぐ危険がある**（いまから実行しようとしている、けがをしている、暴力を受けている最中 など）なら、**すぐに110番か119番**。本人がかけられなければ、了解をとって**こちらからかける**
- 住んでいる地域（都道府県・市区町村）を聞いておくと、つなぎ先を探すときに役立ちます

**③ 占いではなく、専門の窓口につなぐ**

- 「**わたしは占い師なので、このことには、もっと力になれる専門の人がいます**」と、役目の範囲を伝える
- 番号を**伝えるだけで終わらせない**。「いま、いっしょに番号を調べてもいいですか？」と、**その場で一緒に調べる**
- 相手が「電話は苦手」と言ったら、SNSやチャットで相談できる窓口もあることを伝える（厚生労働省の「まもろうよ こころ」のサイトにまとめられています）
- **無理やり**つながせない。「いまは電話できない」と言われたら、番号をメモしてもらい、「つらくなったら、いつでもかけてくださいね」と伝える

**④ 鑑定は、無理に続けない**

- 命式の話にもどさない。「今日は鑑定よりも、このお話のほうが大事だと思います」と伝える
- 料金の話は、この場ではしない。どう扱うか（返金する・次回にふりかえる など）は、**あとで落ちついてから**相手の負担にならない形で決める

**⑤ 自分を守る**

- 相談を、**ひとりでかかえこまない**（④の6）
- 鑑定のあと、気持ちがざわついたら、自分も相談窓口を使ってかまいません

> 💡 **秘密を守ることと、命を守ること**
> 第27章で、「鑑定で聞いたことは外に出さない」と学びました。でも、**命の危険がさしせまっているとき**は、命を守ることが先です。
> そのときも、できるだけ「**あなたの命を守るために、〇〇に連絡させてください**」と本人に伝えて、了解をとってから動きましょう。

### 6. 自分を守る ― 境界線と、燃え尽きない工夫

むずかしい相談を受けると、占い師の心も重くなります。**自分を守ることは、相手を守りつづけるための仕事の一部**です。

| 自分を守る工夫 | 具体的には |
|---|---|
| **時間の境界線** | 鑑定の時間を決めて守る。夜中のメッセージには、すぐ返さない（受付時間を先に伝えておく） |
| **役目の境界線** | 「わたしは占い師。治療・カウンセリング・法律相談はしない」と、自分の中で決めておく |

| **休む** | むずかしい相談のあとは、次の予定を入れない。散歩や、好きなことをする時間をとる |

> 🐱 **まあ先生**
> 「わたしがなんとかしなきゃ」と思うほど、占い師は燃え尽きやすくなるの。
> あなたの役目は、**山小屋の人**。救助隊になる必要はないわ。

## ⑩ 講師ガイド

### この回のねらい
受講者が、むずかしい相談に出会ったとき、**あわてて命式で答えを出そうとせず**、「受けとめる → 確かめる → つなぐ → 続けない → 自分を守る」の型で動けるようになること。そして、**つなぎ先のメモを、自分の手で調べて持ち帰る**こと。講師は、受講者がこの章の話で自分のつらい体験を思い出すこともあると考え、**話したくない人は話さなくてよい**ことを、はじめに伝える。

### 時間配分（45分の例）

| 時間 | 内容 | ポイント |
|---|---|---|
| 0:00〜0:03 | はじめに | 「この章は、つらい話が出てきます。しんどくなったら、休んだり席をはずしたりしてかまいません」と伝える。講師も相談窓口の一覧を手元に置く |
| 0:03〜0:10 | お話：②③ | ひよりさんの失敗を読む。「はげましたのに、なぜ通話が切れてしまったのか」を考える。山小屋の人のたとえと流れの図 |
| 0:10〜0:20 | ④の1〜3：見分け方と5つのステップ | まあ先生のやり直しを、講師が声に出して読む。②の「死にたいと思うくらいつらいですか？」は、全員で一度、声に出して練習する |
| 0:20〜0:25 | ④の4〜5：つなぎ先と言いかえ | 一覧の表を映し、公式サイトを1つ開いて「番号は変わることがあるので、ここで確かめる」と見せる |
| 0:25〜0:32 | 練習問題 | ひとりで解く → 答え合わせ |
| 0:32〜0:42 | ワーク：つなぎ先メモ・台本・約束 | 自分の地域の窓口は、スマホでその場で調べる。台本は2人組で読み合う（役は「相談者」ではなく「台本の読み手」どうしにして、つらい役をさせない） |
| 0:42〜0:45 | まとめ | 「自分を守る約束」を1つずつ発表。最後に、講師から「みなさん自身も、つらいときは窓口を使ってくださいね」と伝える |

### 問いかけの例
- 「山小屋の人が、けがの手当てを自分でしないのは、冷たいからでしょうか？」
- 「『そんなこと言わないで』と言われた相手は、どんな気持ちになるでしょう？」
- 「相手が遠くの県に住んでいたら、どうやってつなぎ先を探しますか？」
- 「自分の気持ちが重くなったとき、だれに、どんなふうに話しますか？（名前や中身を出さずに）」

### よくあるつまずき

| つまずき | 対応 |
|---|---|
| 「死にたいと思いますか？」と聞くのがこわい、と感じる | 聞きにくければ「いなくなりたいと思うことがありますか？」でもよい。はっきり聞くことは、相手のつらさを受けとめるための一歩、と伝える |
| つい、命式で明るい話をしてはげましたくなる | はげます前に、まず受けとめる。命式の話は、落ちついてから別の日に、と④の3でおさらいする |
| 番号を伝えたら、それで役目が終わったと思う | 「一緒に調べる」「電話がむずかしければチャットもある」「いまかけられなくても、メモしてもらう」まで。無理やりつながせないことも大事 |
| 相談者の秘密を守るべきか、迷う | ふだんは守る。でも、命の危険がさしせまっていたら命が先。できるだけ本人に伝えて了解をとってから動く |
| 「ぜんぶ自分でなんとかしなきゃ」と、責任を感じすぎる | 占い師は山小屋の人。救助隊にならなくていい。④の6の境界線を、ワークで自分の約束にしてもらう |
| 受講者自身が、話の途中でつらそうにしている | 無理に参加させない。休憩をとり、終わったあとに個別に声をかけ、④の4の窓口を案内する |
