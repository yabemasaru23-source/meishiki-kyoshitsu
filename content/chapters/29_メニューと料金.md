## ① この章でできるようになること

- 鑑定の**メニューの形**（対面・オンライン・メール鑑定・鑑定書・相性鑑定・年運）と、それぞれの**所要時間**をつかめる
- メニューごとに「**すること・しないこと**（提供範囲）」を決めて書ける
- 料金を、**自分の時間単価**と、**準備・記録の時間**から組み立てられる。相場は数字を覚えるのではなく、**調べ方**を身につける
- モニター価格から通常の料金へ、**経験の段階に合わせて**上げていく道すじを描ける
- **キャンセル・遅刻・延長・返金**のルールと、**記録の保管期間と削除**のルールを、先に決めて書いておける
- 鑑定書をわたすときの注意（アプリの印刷物の中身、自分の言葉で書くこと）がわかる

> 🐱 **まあ先生**
> 料金の話は、なんだか言いにくいわよね。
> でも、メニューと料金とルールがはっきりしていることは、**相談に来る人の安心**でもあるの。
> 「いくらかかるかわからない」「どこまでしてくれるのかわからない」お店には、こわくて入れないでしょう？

## ④ しくみ

### 1. メニューの形 ― どんな形で、どれくらいの時間か

鑑定のメニューには、いくつかの形があります。**最初から全部そろえる必要はありません。**モニター鑑定のふり返りで「求められていた」ものから、2〜3個えらびましょう。

| 形 | 向いている相談・人 | 時間の目安（この教室の考え） | 気をつけること |
|---|---|---|---|
| **対面鑑定** | 表情を見ながら話したい人。はじめての人 | 当日45〜60分＋準備30分＋記録20分 | 場所（静かで、話が聞こえにくい所）。場所代などの実費 |
| **オンライン鑑定**（ビデオ通話） | 遠くに住む人、子育て中などで出かけにくい人 | 当日45〜60分＋準備30分＋記録20分 | 通信が切れたときの決め。**録画・録音はしない**か、するなら先に同意をとる |
| **メール鑑定** | 文章でじっくり読みたい人、話すのが苦手な人 | 書く時間60〜90分＋準備30分 | 相談の文を読んで「聞く」ができないので、**質問をしぼってもらう**。何日以内に返すか決める |
| **鑑定書（PDF）** | 形に残したい人。対面やオンラインの「おまけ」にも | 書く時間60分〜＋見なおし | **アプリの印刷物をそのままわたさない**（このあとの5） |
| **相性鑑定** | パートナー・家族・仕事仲間との関係を見たい人 | 1人分の1.5倍くらい | **その場にいない人の生年月日**を使う。相手の了解があるかを聞く。相手を悪く言わない |
| **年運の鑑定** | 「今年・来年の流れ」を知りたい人。誕生日や年はじめに | 当日30〜45分＋準備20分 | 天中殺の年は「充電期間」として（第21章）。年の区切りは立春、を忘れない |

> 💡 **時間の目安は、自分のふり返りシートで直す**
> 上の時間は、この教室の考えのたたき台です。あなたのモニター鑑定の**ふり返りシートに書いた時間**（「50分、5分オーバー」など）のほうが、ずっと正確です。
> 準備と記録に本当は何分かかったかも、何回か計ってみましょう。

> 💡 **相性鑑定は、2人分の約束**
> 相性鑑定では、その場にいない人の生年月日を使います。第21章の約束⑤（本人に断りなく、人の命式を出して話題にしない）を思い出しましょう。
> - 申しこみのときに「お相手の方は、生年月日を使うことをご存じですか？」と聞く
> - 読むのは「**2人の関係の生かし方**」。相手の性格を悪く言ったり、「別れたほうがいい」と決めつけたりしない（約束④）
> - アプリの相性タブは、**相手の性別の欄が最初「女性」**になっている（自分の欄は「男性」が最初）。2人とも、毎回確かめる

### 2. 提供範囲 ― 「すること」と「しないこと」を書く

メニューごとに、**何をして、何をしないか**を書いておきます。
「しないこと」を書いておくと、あとで「それもやってくれると思っていた」というすれちがいが起きません。

| すること（例） | しないこと（例） |
|---|---|
| 命式を7ステップで読み、**持ち味とくせと使い方**を伝える | 病気・寿命・妊娠・事故を読む（第21章の約束②） |
| 相談ごとに合わせて、**時の流れ（大運・年運）**を伝える | 投資・借金・契約・裁判など、**お金や法律の判断**をする |
| **持ち帰る行動**をひとつ、いっしょに決める | 「別れなさい」「転職しなさい」と、**決める代わり**をする |
| 命式の表（アプリで出したもの）をわたす | お守り・石・お祓いなど、**物やほかのサービスをすすめる**（約束⑥） |
| 鑑定のあと、**〇日以内に1回だけ**、質問に答える（アフターフォロー） | 夜中や、毎日のように続く**無料の相談**を受け続ける |
| | 本人の了解のない**第三者の命式**を読む |

> 🐱 **まあ先生**
> アフターフォローは、やさしさのつもりで「いつでも聞いてね」と言いがちよ。
> でも、それが続くと、あなたが疲れて、ほかの相談者に向ける力がなくなってしまう。
> 「**鑑定のあと7日以内、質問1回まで**」のように、**期間と回数を決めて**メニューに書いておきましょう。

### 3. 料金の考え方 ― 自分の時間から組み立てる

#### ステップ1：自分の時間単価を決める

**時間単価**は、「自分の1時間に、いくらの値をつけるか」です。これは相場ではなく、**あなたが決める数字**です。
決めるときに考えることは、次の3つです。

| 考えること | 例 |
|---|---|
| 1か月に、鑑定に使える時間は何時間か | 本業やくらしの時間を引いて、むりのない時間 |
| その時間で、いくらあれば**続けられる**か | 交通費・場所代・道具代・勉強代・税金（第27章）を引いても、続けたいと思える金額 |
| ほかの仕事の1時間と、くらべてどうか | 「この金額なら、カフェのシフトを1時間ふやすほうがいい」と思うなら、低すぎるかもしれない |

> 時間単価 ＝ その時間で続けられる金額 ÷ 1か月に鑑定に使える時間

#### ステップ2：メニュー1つの「合計の時間」を出す

当日の時間だけで料金を決めると、**準備と記録の時間が、ただ働き**になってしまいます。

> 合計の時間 ＝ 当日の時間 ＋ 準備（命式を出す・点検・下読み） ＋ 記録・お礼の連絡

#### ステップ3：料金のもとを出す

> 料金のもと ＝ 時間単価 × 合計の時間 ＋ 実費（場所代・飲み物代・通話の道具代・支払いの手数料・印刷代 など）

ひよりさんの「対面60分」で、計算のしかたを見てみましょう。

> 💡 **ここで使う数字は、計算のしかたを見るための仮の数字です**
> 相場でも、この教室のおすすめの金額でもありません。あなたの数字は、⑦で自分で決めます。

| | 中身 | 計算 |
|---|---|---|
| 時間単価 | 仮に **2,000円** とする | |
| 合計の時間 | 当日60分 ＋ 準備30分 ＋ 記録・連絡20分 ＝ **110分** | |
| 時間のぶん | | 2,000円 × 110 ÷ 60 ＝ **約3,667円** |
| 実費 | カフェの飲み物代（2人分）など | ＋ 実費 |
| 料金のもと | | 約3,667円 ＋ 実費 → 切りのいい数字にする |

> 🙋 **ひより**
> 当日の60分だけで計算したら2,000円だったのに、準備と記録を入れたら、ほとんど2倍になりました……！
> わたし、準備の時間のこと、ぜんぜん考えていませんでした。

> 🐱 **まあ先生**
> そうなの。だから「なんとなく」決めると、続けるほど疲れてしまうのよ。
> 「料金のもと」は、**これより安くすると、自分がすりへってしまう線**だと思っておいてね。

#### ステップ4：相場を調べる（数字を覚えるのではなく、調べ方を身につける）

料金のもとが出たら、ほかの鑑定士がどんなメニューを出しているかも調べます。
相場は、地域・形・時間・経験・中身によって大きくちがい、時期によっても変わります。だから、**この教材では相場の数字は書きません**。かわりに、調べ方を覚えましょう。

| 手順 | やること |
|---|---|
| ① 調べる先を決める | 鑑定士の個人のサイト、占いの予約サイト、地域のイベントや占いの館の案内 など |
| ② **10件以上**を表にする | 形・時間・料金・**含まれるもの**（鑑定書つき、アフターフォローつき など）・経験の書き方 |
| ③ **1分あたり**に直す | 料金 ÷ 時間。時間がちがうメニューどうしでも、くらべられるようになる |
| ④ 真ん中あたりを見る | いちばん高い人・いちばん安い人ではなく、**まん中にたくさん集まっている所**を見る |
| ⑤ 高い・安いの理由を見る | 経験の長さ、中身の多さ、場所、ねらっている相談者 など |
| ⑥ 自分の「料金のもと」とくらべる | 料金のもとより相場がかなり低い形は、**メニューにしない**か、時間や中身を見なおす |

> 💡 **調べたサイトの文章は、写さない**
> 調べるのは、形・時間・料金・中身の組み合わせだけ。ほかの人のメニューの説明文や鑑定の文を、自分のサイトに写してはいけません（文章には書いた人の権利があります）。

#### ステップ5：経験の段階に合わせて上げていく

料金は、一度決めたらずっと同じ、ではありません。経験に合わせて、**段階的に**上げていきます。

| 段階 | 料金の決め方 | 相手への伝え方 |
|---|---|---|
| **モニター**（〜10〜30人） | 無料、または実費だけ | 「練習中の鑑定です」（第26章） |
| **はじめての有料**（お試しの価格） | 料金のもとくらいから。**期限か人数を決める** | 「〇月末まで（〇人まで）の、はじめての方向けの価格です」 |
| **通常の料金** | 料金のもと ＋ 経験・中身の分 | メニュー表に書く |
| **見直し**（半年〜1年ごと） | 予約の入り方、リピート、感想の数、自分の疲れ方を見る | 上げるときは**1か月以上前に知らせる**。すでに予約している人は、前の料金のまま |

> 💡 **モニター価格からの移りかた**
> - モニターをお願いするときに、「**モニターは〇人まで（〇月まで）。そのあとは有料の鑑定になります**」と、先に伝えておく
> - モニターだった人に、「次から有料です」と**だまって**料金をとらない。前もって、メニュー表といっしょに知らせる
> - 「モニターの方は、1回目の有料鑑定は〇〇つき」のような**お礼**を用意してもよい（期限を書く）

> 🐱 **まあ先生**
> やってはいけないのは、**不安をあおって、高いメニューへ連れていく**こと。
> 「このままだと大変なので、もっと長いコースが必要です」は、第21章の約束①と⑥をやぶる言い方よ。
> どのメニューをえらぶかは、**相談する人が、メニュー表を見て決める**の。

### 4. ルールを先に決めて、書いておく

もめごとの多くは、「**決めていなかった**」ことから起きます。メニュー表といっしょに、次のルールを書いておきましょう。
ルールは、申しこみの**前に**、相手が読める所（メニュー表・申しこみの案内）に書きます。

| ルール | 決めること | 書き方の例 |
|---|---|---|
| **キャンセル** | いつまでなら料金がかからないか。当日・連絡なしのときはどうするか | 「前日までのご連絡は、料金はかかりません。当日のキャンセルは、料金の〇割をいただきます」 |
| **遅刻** | 遅れた分は延ばすか、終わりの時間は同じか | 「遅れた場合も、終わりの時間は変わりません」 |
| **延長** | 延長するときの聞き方と料金 | 「終わりの5分前にお知らせします。延長するかどうかは、料金をお伝えしてから、あなたに決めていただきます」 |
| **返金** | どんなときに返すか | 「こちらの都合で鑑定ができなかったときは、全額お返しします」 |
| **支払い** | いつ・どうやって払ってもらうか | 「鑑定の前日までに、〇〇でお支払いください」 |
| **通信のトラブル**（オンライン） | 切れたときにどうするか | 「通信が切れて続けられなかったときは、日をあらためて続きを行います」 |
| **録音・録画** | するか、しないか | 「鑑定の録音・録画はしません。メモをご希望の方には、要点をお送りします」 |
| **年齢** | 未成年の申しこみをどうするか | 「18歳未満の方の鑑定は、お受けしていません」 |

> 💡 **「当たらなかったから返して」と言われたら**
> 鑑定は、未来を約束するものではありません。だからこそ、メニュー表に「**鑑定は、持ち味と時の流れを読み、考える材料をお伝えするものです。結果を約束するものではありません**」と、先に書いておきます。
> そのうえで、相手の気持ちは受けとめましょう。「どこが合わないと感じましたか？」と聞けば、それも大切なふり返りになります（第26章）。

> 💡 **キャンセル料を高くしすぎない**
> 消費者契約法という法律では、キャンセル料などのうち、同じような解約で事業者にふつう生じる損害（平均的な損害）を**こえる部分は無効**になるとされています。
> キャンセル料は、空いた時間や準備の分に見合う程度にしましょう。くわしいことは第27章、迷ったら消費生活センターなどの公的な窓口で確かめてください。

> 💡 **ネットで申しこみを受けて売るときは**
> インターネットで申しこみを受けて、お金をいただく形になると、**法律で表示しなければならないこと**が出てきます。これは第27章「お金と法律の基本」で学びます。

### 5. 鑑定書をわたすときの注意

#### アプリの「PDF・印刷」で出るもの

アプリには「🖨 PDF・印刷」のボタンがあります。アプリの中身を読んで確かめると、押したときに出るものは、次のとおりです。

| 出るもの | 中身 |
|---|---|
| 表紙 | 「命式鑑定書」、入れた名前に「様」、生年月日と性別、発行日、そして**アプリを提供している会社の名前と鑑定士の名前** |
| 各ページの上 | 「〇〇 さんの命式鑑定書」、生年月日・性別・出力日、**アプリの提供元の名前** |
| 本文 | 命式・五行・鑑定・禅（今日のカード）・**営業（この方への営業戦術）**・感動・総合の**すべてのタブ**。姓と名を入れていれば姓名判断、相性を出していれば相性も入る |
| 巻末 | 「総合鑑定書」の文章と、**アプリの提供元の署名** |

つまり、ボタンを押してそのまま出したPDFは、
- **あなたではない人の名前**が、表紙・各ページ・巻末に入っている
- 文章は、**アプリが書いた文**（第19章で学んだとおり、そのまま読み上げたり、わたしたりしないもの）
- 「この方への**営業戦術**」のように、**相談する人にわたすためではないページ**も入っている

ということです。

> 🐱 **まあ先生**
> だから、アプリのPDFを**そのまま「わたしの鑑定書」として売ってはいけない**の。
> アプリは、あなたが命式を出して読むための**道具**。お客さまにわたす鑑定書は、**あなたの言葉で書いたもの**よ（第19章）。
> 命式の表をそえたいときは、「**命式の表は、アプリで出したものです**」と伝えたうえで、印刷の画面の「ページ」の指定で、**命式と五行のページだけ**をPDFにするといいわ。

> 💡 **アプリの印刷物を、有料のメニューに入れたいとき**
> アプリの表や文章を、お金をいただくメニューの一部に使ってよいかは、アプリの提供元の考えによります。迷ったら、アプリの提供元に確かめましょう。
> いちばん安心なのは、**命式の表は自分で書き写す（または「アプリで出したもの」と明記してそえる）、本文は自分で書く**、という形です。

#### 自分の鑑定書の組み立て（例）

| | 中身 |
|---|---|
| 1 | 表紙：呼び名、鑑定日、**あなたの名前（屋号）** |
| 2 | 命式の表（アプリで出したものと明記。時柱が2とおりあれば、そのことも） |
| 3 | あなたの持ち味（日干・五行・月柱の星）と、根拠の星 |
| 4 | くせと使い方 |
| 5 | ご相談へのヒント |
| 6 | 時の流れ（大運・年運。天中殺は「充電期間」として） |
| 7 | 持ち帰る行動（鑑定で、相手が自分でえらんだもの） |
| 8 | 注意書き：「この鑑定書は、持ち味と時の流れを読んだものです。医療・法律・お金の判断の代わりにはなりません」「流派によって見方が異なる所があります（〇〇の所）」 |

### 6. 記録の保管期間と削除

鑑定の記録には、生年月日・相談の中身など、**その人を特定できる大切な情報**が入っています（第21章の約束⑤）。
お金をいただいて鑑定するようになったら、記録のルールも決めて、申しこみの案内に書いておきます。

| 決めること | 例 |
|---|---|
| **何を残すか** | 呼び名、生年月日・出生時刻、相談の要点、伝えたこと、持ち帰る行動、次の約束。**本名・住所・家族の名前など、なくても鑑定できるものは残さない** |
| **どこに残すか** | 1か所にまとめる。パスワードやロックをかける。人と共用の端末に残さない |
| **いつまで残すか** | 「最後の鑑定から〇か月」など、**期間を決めて、申しこみのときに伝える** |
| **どうやって消すか** | アプリの「保存済みの命式」の「×」、「JSON で書き出す」で作ったファイル、メールやLINEのやりとり、紙のメモ（細かく切ってすてる）。**全部の置き場所**を消す |
| **消してと言われたら** | 期間の前でも、すぐに消して「消しました」と伝える |

> 💡 **お金の記録は、べつに考える**
> 料金を受けとった記録（いつ・いくら）は、税金の申告などのために、決められた期間とっておく必要があることがあります。相談の中身の記録とは、**分けて**保管しましょう。くわしいことは第27章で学びます。

> 💡 **個人情報をあつかうきまり**
> 仕事として人の情報をあつかうと、個人情報保護法という法律のきまりも関係してきます。くわしいことは第27章、または個人情報保護委員会の案内で確かめてください。

### 3行まとめ

1. メニューは**形・時間・すること・しないこと**を書く。まずはモニターで求められた2〜3個から。相性鑑定は、その場にいない人の了解も大切に
2. 料金は「**時間単価 × （当日＋準備＋記録）＋ 実費**」で料金のもとを出し、相場は**調べ方**で確かめる。経験に合わせて段階的に上げ、上げるときは前もって知らせる
3. キャンセル・延長・返金・記録のルールは**先に書く**。アプリのPDFには提供元の名前と全部のタブが入るので、**鑑定書は自分の言葉で**書く

## ⑩ 講師ガイド

### この回のねらい
受講者が、料金を「なんとなく」や「ほかの人のまね」ではなく、**自分の時間と中身から組み立てる**ようになること。そして、メニュー・料金・ルールをはっきり書くことが、**相談する人の安心**であり、自分がすりへらずに続けるための守りでもある、と感じてもらうこと。

### 時間配分（60分の例）

| 時間 | 内容 | ポイント |
|---|---|---|
| 0:00〜0:05 | チェックイン | 「入るのをためらったお店と、安心して入れたお店。何がちがいましたか？」 |
| 0:05〜0:15 | お話：②③④の1〜2 | カフェのメニュー表のたとえ。「しないこと」を書く意味を強調する |
| 0:15〜0:30 | ④の3：料金の組み立て | 仮の数字で、講師といっしょに1回計算する。**相場の数字は講師も言わない**。調べ方の表を見せる |
| 0:30〜0:40 | ④の4〜6・⑤ | ルールの例を読む。アプリの印刷プレビューを画面に映し、表紙・各ページの名前と、営業のページを確かめる |
| 0:40〜0:55 | ワーク | メニュー表と時間単価の計算を書く → ペアで「しないこと」と「ルール」を読み合い、きびしすぎ・あいまいな所を指摘し合う |
| 0:55〜1:00 | まとめ | 「わたしが最初に出すメニュー」を1人ずつ |

### 問いかけの例
- 「準備と記録に、本当は何分かかっていましたか？ モニターのふり返りシートを見てみましょう」
- 「『しないこと』を書いておかないと、どんなすれちがいが起きそうですか？」
- 「アプリのPDFを、そのままお客さまにわたすと、何がこまるでしょう？」

### よくあるつまずき

| つまずき | 対応 |
|---|---|
| 「相場はいくらですか？」と、数字を聞きたがる | 相場は地域・形・時間・中身・時期でちがうので、この教室では言わない。調べ方の表で、自分で10件調べてもらう |
| 自信がなくて、料金のもとより安くしようとする | 料金のもとは「これより安いと、自分がすりへる線」。安くしたいなら、期限と人数を決めた「お試しの価格」にする |
| 計算の例の「2,000円」を、そのまま自分の時間単価にする | 計算のしかたを見るための仮の数字だと、もう一度伝える。自分の1か月の時間と、続けられる金額から出しなおす |
| ルールを書くと「感じが悪い」と思う | ルールは相手の安心のため。「先に書いてあるお店のほうが、入りやすい」というカフェのたとえにもどる |
| キャンセル料をきびしくしすぎる | 空いた時間と準備の分に見合う程度に。法律で無効になる部分があることを伝え、くわしくは第27章・公的な窓口へ |
| アプリのPDFを、そのまま鑑定書として売ろうとする | 印刷プレビューで、提供元の名前・営業のページを一緒に確かめる。本文は自分の言葉で書き、表は「アプリで出したもの」と明記する |
| 相性鑑定で、その場にいない人を悪く言ってしまう | 第21章の約束④⑤にもどる。「2人の関係の生かし方」を読む、と言いかえる |
