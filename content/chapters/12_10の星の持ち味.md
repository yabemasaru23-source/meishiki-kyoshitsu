## ① この章でできるようになること

- 比肩から印綬までの10個の星を、**ニックネームとキーワード**で言えるようになる
- 1つの星の「**持ち味**」と「**くせ（出すぎたとき）**」を、セットで説明できる
- 同じグループの2つの星を、「**かたよる（一点集中・型やぶり）**」と「**ととのう（安定・型どおり）**」でくらべられる
- 昔「凶星（きょうせい）」と呼ばれた星を、**こわがらせずに「強い力の使い方」**として伝えられる
- 命式にある星のキーワードをつないで、**人物像を一文で**言えるようになる

> 🐱 **まあ先生**
> 第11章では、星の「出し方」を学んだわね。この章は、星の「中身」よ。
> 10人のキャラクターに会いに行くつもりで、気楽に読んでね。**全部覚えなくていい**の。まずは、自分の命式にいる星から仲良くなりましょう。

## ③ たとえ話：あなたのまわりの5種類の人、それぞれ2人ずつ

第11章で、命式の漢字を「**わたしのまわりの5種類の人**」に分けました。

| まわりの人 | グループ |
|---|---|
| 👫 友だち・きょうだい（わたしと同じ仲間） | 仲間の星 |
| 🎨 わたしが生み出すもの（作品・言葉・アイデア） | 表現の星 |
| 💰 わたしが手に入れるもの（お金・成果・ご縁） | 財の星 |
| 👔 わたしをきたえるもの（ルール・責任・社会） | 官の星 |
| 📚 わたしを育ててくれるもの（親・先生・学び） | 印の星 |

じつは、どのグループにも**性格のちがう2人**がいます。たとえば「友だち」でも、

- ひとりで黙々と走るのが好きな友だち
- みんなを巻きこんで「勝ちに行こう！」と言う友だち

がいますよね。これが、**陰陽が「同じ」星**と**「ちがう」星**のちがいです。

> 💡 **第11章のおさらい：「同じは、かたよる」**
> 陰陽が**同じ**だと、力がひとつの方向に**かたよって**強く出る → 一点集中・型やぶり・波がある
> 陰陽が**ちがう**と、陰と陽がつりあって**ととのう** → 安定・型どおり・長つづきする

5グループ × 2人 ＝ **10人のキャラクター**。図にすると、こうなります。

![10の星のキャラクター一覧。横に5つのグループ（仲間・表現・財・官・印）、上の段が陰陽が同じ「かたよる」星（比肩＝わが道ランナー、食神＝ごきげん料理人、偏財＝顔の広い旅人、偏官＝かけつけ隊長、偏印＝ひらめき発明家）、下の段が陰陽がちがう「ととのう」星（劫財＝勝負キャプテン、傷官＝するどい芸術家、正財＝コツコツ管理人、正官＝信頼の委員長、印綬＝学び好きの学者）](assets/img/ch12-stars.svg)

> 🙋 **ひより**
> あれ？ 仲間の星と表現の星は、下の段（ちがう）のほうが劫財と傷官で、なんだか強そうな名前……。

> 🐱 **まあ先生**
> よく気づいたわね。仲間の星と表現の星だけは、**下の段の星にも「勢い」がある**の。
> 劫財は「勝負」、傷官は「するどさ」。どちらも、ととのった形の中に**熱い芯**がある星よ。くわしくは④で話すわ。

## ④ しくみ

### 1. 星の図鑑の読み方

ここから、10人のキャラクターを1人ずつ紹介します。どの星も、同じ項目で書いています。

| 項目 | 中身 |
|---|---|
| ニックネーム | その星をひとことで言うと |
| キーワード | 鑑定で使う3つの言葉 |
| 持ち味 | その星のいちばんの良さ |
| くせ | 力が**出すぎたとき**に見える姿。悪いところではなく、持ち味の「うら側」 |
| 仕事で／人間関係で | 毎日の生活での出かた |
| 伸ばし方 | 持ち味を生かすコツ |

> 🐱 **まあ先生**
> 「くせ」は、持ち味と**同じ力**なの。強火で料理すればおいしく焼けるけど、ほうっておくとこげる。火が悪いんじゃなくて、火加減の問題よね。
> だから鑑定では、くせを伝えるときも、**かならず持ち味とセットで**伝えましょう。

### 2. 👫 仲間の星 ― 比肩と劫財

わたしと**同じ五行**の星。「自分の力」「自分らしさ」をあらわします。

#### 比肩（ひけん）― わが道ランナー 🏃

| 項目 | 中身 |
|---|---|
| キーワード | **自立・マイペース・やりぬく** |
| 持ち味 | 人にたよらず、自分の足で立てる。決めたことを最後までやりぬく芯の強さ。だれとでも対等につき合える |
| くせ | 人の意見を聞くのが苦手。「ひとりでやったほうが早い」と、かかえこむ。がんこに見える |
| 仕事で | 自分で考えて進められる仕事、任せてもらえる立場で力を出す。こまかく指示されると息苦しい |
| 人間関係で | 上下より**横ならび**の関係が心地いい。べたべたしない、さっぱりした友情 |
| 伸ばし方 | 「自分で決める」場面をふやす。ときどき「手伝って」と言う練習をすると、もっと遠くまで行ける |

#### 劫財（ごうざい）― 勝負キャプテン 🏆

| 項目 | 中身 |
|---|---|
| キーワード | **勝負強さ・巻きこむ力・負けずぎらい** |
| 持ち味 | 「ここが勝負」というときに、ぐっと力が出る。仲間を巻きこんで、チームで目標をうばいに行く行動力 |
| くせ | 勢いで決めてしまう。勝ち負けにこだわりすぎる。気前がよすぎて、お金や力を出しすぎる |
| 仕事で | 目標や競争がある仕事、チームで成果を競う場面に強い。営業・スポーツ・立ち上げなど |
| 人間関係で | 面倒見がよく、仲間を守る親分肌。ただ、ライバル心にも火がつきやすい |
| 伸ばし方 | 「勝ちたい相手」を人ではなく**目標**にする。決める前に、ひと呼吸おく習慣を |

> 💡 **くらべてみよう：比肩と劫財**
>
> | | 比肩（陰陽が同じ） | 劫財（陰陽がちがう） |
> |---|---|---|
> | 力の向き | **自分ひとり**に集中 | **まわりを巻きこんで**外へ |
> | 走り方 | 自分のペースで、長く | ここ一番で、力強く |
> | ひとことで | わが道を行く | みんなで勝ちに行く |
>
> 仲間の星だけは「かたよる＝型やぶり」より、「**比肩＝ひとりの力／劫財＝チームの力**」でくらべると、わかりやすくなります。

### 3. 🎨 表現の星 ― 食神と傷官

わたしが**生み出す**五行の星。言葉・作品・アイデア・楽しみなど、「外へ出していく力」です。

#### 食神（しょくじん）― ごきげん料理人 🍳

| 項目 | 中身 |
|---|---|
| キーワード | **楽しむ・おおらか・味わう** |
| 持ち味 | 毎日を楽しむ天才。おいしいもの、心地いいものを味わい、それを人にもおすそ分けできる。いるだけで場がなごむ |
| くせ | のんびりしすぎる。楽なほうへ流れやすい。いやなことを後まわしにする |
| 仕事で | 食・遊び・趣味・もてなしなど、「人を楽しませる」仕事で光る。自分が楽しめていると成果も出る |
| 人間関係で | 人なつっこく、まわりから好かれる。争いごとは苦手 |
| 伸ばし方 | 「好き」「楽しい」を、**かくさずに外へ出す**。小さなしめきりを作ると、のんびりが「ゆとり」に変わる |

#### 傷官（しょうかん）― するどい芸術家 🎨

| 項目 | 中身 |
|---|---|
| キーワード | **感性・こだわり・本音** |
| 持ち味 | 人が気づかない美しさや、まちがいに気づける**するどい感性**。ありきたりでは満足しない、こだわりの職人 |
| くせ | 思ったことを、言葉がするどいまま言ってしまう。決まりや権威に反発しやすい。傷つきやすい |
| 仕事で | デザイン・技術・企画・批評など、「もっと良くする」仕事で光る。古いやり方を変える改革役 |
| 人間関係で | 好き嫌いがはっきり。わかり合える少数の人と、深くつながる |
| 伸ばし方 | するどさを「**批判**」ではなく「**作品**」に変える。言う前に「どう言えば相手に届くか」を1回考える |

> 💡 **くらべてみよう：食神と傷官**
>
> | | 食神（陰陽が同じ） | 傷官（陰陽がちがう） |
> |---|---|---|
> | 表現の向き | **自分が楽しい**から出す | **もっと良くしたい**から出す |
> | 雰囲気 | ゆったり・まるい | ぴりっと・するどい |
> | ひとことで | 楽しむ人 | みがく人 |
>
> 食神は「かたよる」ぶん、**好きなことに一点集中**。傷官は、陰陽がちがうぶん「ととのった美しさ」を求める目を持ち、その目がするどさになって出ます。

### 4. 💰 財の星 ― 偏財と正財

わたしが**おさえる（動かす）**五行の星。お金・成果・人とのご縁など、「手に入れて、動かすもの」です。

#### 偏財（へんざい）― 顔の広い旅人 🧳

| 項目 | 中身 |
|---|---|
| キーワード | **人脈・サービス精神・動かす** |
| 持ち味 | 人と人をつなぐのが上手。たくさんの場所に顔を出し、ご縁を広げる。お金やものを「回して」生かす才能 |
| くせ | 八方美人に見える。あれこれ手を広げて、いそがしくなりすぎる。お金が入るのも出るのも大きい |
| 仕事で | 営業・販売・企画・つなぎ役など、人が動く仕事で光る。人の役に立つと、自然に成果がついてくる |
| 人間関係で | だれにでもやさしく、気前がいい。友だちが多く、場をもりあげる |
| 伸ばし方 | 「たくさん」の中から、**大事にするご縁を選ぶ**。お金は「回す分」と「残す分」を分けておく |

#### 正財（せいざい）― コツコツ管理人 🌱

| 項目 | 中身 |
|---|---|
| キーワード | **堅実（けんじつ）・誠実・積み上げ** |
| 持ち味 | 毎日の小さな積み上げを、決してやめない。お金や時間をきちんと管理し、約束を守る。長く信頼される |
| くせ | 慎重（しんちょう）すぎて、チャンスを見送る。変化が苦手。けちと言われることも |
| 仕事で | 経理・管理・事務・品質など、正確さと継続が大事な仕事で光る。任されたことを確実に仕上げる |
| 人間関係で | 少しの人と、長く、まじめにつき合う。家族や身近な人を大切にする |
| 伸ばし方 | 積み上げてきた力を信じて、**ときどき小さな冒険**を。計画に「遊びの予算」を入れておく |

> 💡 **くらべてみよう：偏財と正財**
>
> | | 偏財（かたよる） | 正財（ととのう） |
> |---|---|---|
> | お金・ご縁 | **大きく動かす**・広げる | **こつこつ貯める**・守る |
> | 動き方 | あちこちへ、すばやく | 決まった道を、毎日 |
> | ひとことで | 回す人 | 育てる人 |

### 5. 👔 官の星 ― 偏官と正官

わたしを**おさえる（きたえる）**五行の星。ルール・責任・社会・目上の人など、「わたしをきたえるもの」です。

#### 偏官（へんかん）― かけつけ隊長 🚒

| 項目 | 中身 |
|---|---|
| キーワード | **行動力・責任感・ピンチに強い** |
| 持ち味 | 「だれかがやらなきゃ」という場面で、真っ先に動ける。困っている人を放っておけない正義感。きびしい場面でこそ力が出る |
| くせ | せっかちで、休むのが下手。自分にも人にもきびしくなりすぎる。無理を引き受けてしまう |
| 仕事で | 現場のリーダー、トラブル対応、体を動かす仕事、スピードが大事な仕事で光る |
| 人間関係で | 頼られる兄貴分・姉御肌。言葉はストレートだが、根はやさしい |
| 伸ばし方 | 「全部ひとりで背負わない」と決める。**休むことも仕事**と考える。力を向ける先を、自分で選ぶ |

#### 正官（せいかん）― 信頼の委員長 📋

| 項目 | 中身 |
|---|---|
| キーワード | **責任感・きちんと・信用** |

| 人間関係で | 礼儀正しく、約束を守る。目上の人からかわいがられる |
| 伸ばし方 | 「ちゃんと」の基準を、**ときどきゆるめる**。自分で決めたルールで動く場面も作る |

> 💡 **くらべてみよう：偏官と正官**
>
> | | 偏官（かたよる） | 正官（ととのう） |
> |---|---|---|
> | 責任のはたし方 | **ピンチに飛びこんで**解決する | **ふだんからきちんと**守る |

> | ひとことで | 動いて守る人 | 整えて守る人 |
>
> ひよりさんが本で見た「七殺」は、偏官の昔の呼び名です。日干をおさえる力が**かたよって強く**働くので、昔の人は「きびしい星」と考えました。でも、その強さは「**ピンチに負けない力**」そのものです。

### 7. 昔「凶星」と呼ばれた星は、「強い力」の星

昔の本では、**劫財・傷官・偏官・偏印**などが「凶星（きょうせい）」と呼ばれることがありました。
でも、この教室では、星に「良い・悪い」はつけません。

| 星 | 昔こわがられた理由 | この教室での読み方（強い力の使い方） |
|---|---|---|
| 劫財 | 財（お金）をうばう、と考えられた | **勝負強さ**。仲間と目標を取りに行く力。お金は「出す前にひと呼吸」 |
| 傷官 | 官（ルール・目上）を傷つける、と考えられた | **改革する力**。古いものを良くする目。言葉は「届く形」にして出す |
| 偏官 | 日干（わたし）をきびしくおさえる、と考えられた | **ピンチに強い力**。人を守る行動力。休むことをセットに |
| 偏印 | 食神（楽しみ）をじゃまする、と考えられた | **ひらめく力**。人とちがう視点。思いつきを形に残す |

> 🐱 **まあ先生**
> 昔の人がこわがったのは、**力が強くて、使い方をまちがえると目立つ**からなの。
> 逆に言えば、使い方さえわかれば、命式の中でいちばん頼りになる星になるわ。
> 鑑定で「凶星があります」なんて言う必要は、まったくないの。「**強い力を持っていますね。こう使うと生きますよ**」と伝えればいいのよ。

> 🙋 **ひより**
> 「七殺」って聞いてこわかったけど、「かけつけ隊長」なら……たしかに、カフェでトラブルがあると、わたし真っ先に飛んでいきます！

## ⑤ アプリで見てみよう

> 📱 **アプリで見てみよう：鑑定タブ**
> 1. [命式アプリ](https://qmw.co.jp/meishiki/)で自分の命式を出し、「**鑑　定**」タブを開きます
