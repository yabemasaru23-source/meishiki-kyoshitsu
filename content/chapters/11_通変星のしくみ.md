## ① この章でできるようになること

- 通変星が「**日干（わたし）から見た、ほかの漢字との関係**」だとわかる
- 10個の通変星が「**5つの関係 × 陰陽が同じか・ちがうか**」でできていることを説明できる
- 命式の天干（上の段）を見て、**アプリを見ずに通変星を自分で出せる**ようになる
- 日柱の通変星が「—」になっている理由を説明できる

> 🐱 **まあ先生**
> この章は、命式の読み方でいちばんの山場よ。でも、ここを越えると一気に見える景色が変わるわ。
> 必要な道具は2つだけ。**第3章の「相生・相剋」の図**と、**第4章の「十干の陰陽」**。手元に用意してね。

## ② ひよりの疑問

> 🙋 **ひより**
> 命式の表に「印綬」とか「偏官」とか、むずかしい漢字が並んでいて……。
> 本を見たら、通変星は10種類あって、それぞれに意味があって、日干が10種類あるから組み合わせは100通り……。
> むり！ ぜったい覚えられないです！

> 🐱 **まあ先生**
> 100通りを覚える人なんていないわ。わたしだって覚えていないもの。
> 通変星はね、**たった1つの質問の答え**なの。
> 「**わたし（日干）から見て、この漢字は何者？**」
> この質問の答え方さえわかれば、100通りぜんぶ、その場で出せるのよ。

## ③ たとえ話：あなたのまわりの5種類の人

あなたのまわりにいる人を、**「わたしとの関係」**で分けてみましょう。だいたい5種類に分けられます。

| まわりの人 | わたしとの関係 | 通変星のグループ |
|---|---|---|
| 👫 **友だち・きょうだい** | わたしと同じ仲間。肩をならべる | 仲間の星（比肩・劫財） |
| 🎨 **わたしが生み出すもの** | わたしの作品、こども、言葉、アイデア | 表現の星（食神・傷官） |
| 💰 **わたしが手に入れるもの** | わたしが動かし、つかみとるもの。お金、成果、人とのご縁 | 財の星（偏財・正財） |
| 👔 **わたしをきたえるもの** | わたしにルールや責任を与える。上司、仕事、社会 | 官の星（偏官・正官） |
| 📚 **わたしを育ててくれるもの** | わたしに知恵や安心をくれる。親、先生、学び | 印の星（偏印・印綬） |

![日干（わたし）を真ん中にして、5種類の関係が取りかこむ図。同じ五行は仲間、わたしが生むのは表現、わたしがおさえるのは財、わたしをおさえるのは官、わたしを生むのは印](assets/img/ch11-wheel.svg)

命式の中にある漢字も、これと同じです。
日干（わたし）以外の漢字は、ぜんぶ**「わたしにとっての、この5種類のどれか」**なのです。

そして、5種類それぞれに「**陰陽が同じ人**」と「**陰陽がちがう人**」がいるので、5 × 2 ＝ **10個の星**になります。
これが通変星のしくみの、すべてです。

## ④ しくみ

### 1. 主役はいつも「日干」

通変星は、**かならず日干から見て**決まります。
日干とは、**日柱の上の段の漢字**のこと。命式の中で「あなた自身」をあらわす、いちばん大事な1文字です（くわしくは第8章）。

> 💡 **だから、日柱の通変星は「—」**
> アプリの命式で、日柱の通変星のマスだけが「—」になっています。
> 日柱の上の段は日干、つまり「わたし」そのもの。**自分から見た自分**には、関係の名前がつけられないからです。

### 2. 五行の5つの関係（第3章のおさらい）

第3章で学んだ、相生と相剋の関係を思い出してください。

- **相生**（助ける・生む）：木 → 火 → 土 → 金 → 水 → 木 …
- **相剋**（おさえる）：木 → 土 → 水 → 火 → 金 → 木 …

日干の五行と、相手の漢字の五行をくらべると、関係はかならず次の5つのどれかになります。

| 関係 | 見分け方 | グループ |
|---|---|---|
| ① 同じ五行 | 日干と相手が同じ五行 | **仲間の星** |
| ② わたしが生む | 相生の矢印が、日干 → 相手 | **表現の星** |
| ③ わたしがおさえる | 相剋の矢印が、日干 → 相手 | **財の星** |
| ④ わたしをおさえる | 相剋の矢印が、相手 → 日干 | **官の星** |
| ⑤ わたしを生む | 相生の矢印が、相手 → 日干 | **印の星** |

### 3. 陰陽が「同じ」か「ちがう」かで、2つに分かれる

第4章で学んだとおり、十干にはそれぞれ陰陽があります。

| | 陽（＋） | 陰（−） |
|---|---|---|
| <span class="g-moku">木</span> | 甲 | 乙 |
| <span class="g-ka">火</span> | 丙 | 丁 |
| <span class="g-do">土</span> | 戊 | 己 |
| <span class="g-kin">金</span> | 庚 | 辛 |
| <span class="g-sui">水</span> | 壬 | 癸 |

5つのグループそれぞれが、陰陽が**同じ**か**ちがう**かで、2つの星に分かれます。

| グループ | 陰陽が **同じ** | 陰陽が **ちがう** |
|---|---|---|
| ① 仲間の星 | **比肩**（ひけん） | **劫財**（ごうざい） |
| ② 表現の星 | **食神**（しょくじん） | **傷官**（しょうかん） |
| ③ 財の星 | **偏財**（へんざい） | **正財**（せいざい） |
| ④ 官の星 | **偏官**（へんかん） | **正官**（せいかん） |
| ⑤ 印の星 | **偏印**（へんいん） | **印綬**（いんじゅ） |

> 💡 **覚え方：「同じは、かたよる」**
> 陰陽が同じだと、力がひとつの方向に**かたよって**強く出ます。だから「偏（かたよる）」の字がつきます（偏財・偏官・偏印）。
> 陰陽がちがうと、陰と陽がつりあって**ととのった**形になります。だから「正」の字がつきます（正財・正官）。
> 仲間の星と表現の星だけは、昔からの特別な名前（比肩・劫財、食神・傷官）なので、「左が同じ・右がちがう」とセットで覚えましょう。
> 印の星の「陰陽がちがう」ほうは、「正印」ではなく**印綬**という名前で呼ぶ流派が多く、アプリもこの呼び方です。

### 4. 通変星を出す「3ステップ」

ここまでを、手順にまとめます。**この3ステップだけで、どの命式の通変星も出せます。**

> 🐱 **まあ先生**
> **ステップ1**　日干の五行と陰陽を確かめる
> **ステップ2**　相手の漢字の五行が、日干から見て ①〜⑤ のどの関係かを決める（相生・相剋の図で矢印をたどる）
> **ステップ3**　陰陽が同じか、ちがうかで、2つの星のどちらかに決める

### 6. 蔵干通変星も、同じしくみ

アプリの命式には「**蔵干通変星**」という段もあります。
これは、下の段（地支）の中にかくれている漢字（蔵干）を、**同じ3ステップで日干から見たもの**です。

ひよりさんの年柱の蔵干は「丙」。丙は<span class="g-ka">火</span>で、火は金をおさえる（官の星）。丙は陽、辛は陰で陰陽がちがうので **正官**。
アプリの蔵干通変星も「正官」になっています。しくみはまったく同じです。

> 💡 **通変星と蔵干通変星のちがい（入り口だけ）**
> 通変星（上の段から出した星）は、**外から見える、その人の表の顔**。
> 蔵干通変星（かくれた漢字から出した星）は、**内側にある本音や、あとから出てくる力**。
> くわしい読み方は、第10章（蔵干）と第13章で学びます。

## ⑥ 練習問題

まずは、日干と相手の漢字だけで練習します。④の4の3ステップと、陰陽の表を見ながら解いてください。

```work
id: 11.quiz1
type: quiz
label: 通変星を出す練習（基本）
questions:
  - q: 日干が「甲（陽の木）」の人から見て、「甲」は？
    options: [比肩, 劫財, 食神, 偏財]
    answer: 比肩
    explain: 同じ五行（木）で、陰陽も同じ（陽と陽）。仲間の星の「同じ」ほうなので比肩です。
  - q: 日干が「丙（陽の火）」の人から見て、「戊（陽の土）」は？
    options: [食神, 傷官, 偏財, 偏印]
    answer: 食神
    explain: 火は土を生む（火 → 土）ので、わたしが生む＝表現の星。丙も戊も陽で陰陽が同じなので、食神です。
  - q: 日干が「庚（陽の金）」の人から見て、「乙（陰の木）」は？
    options: [偏財, 正財, 偏官, 正官]
    answer: 正財
    explain: 金は木をおさえる（金 → 木）ので、わたしがおさえる＝財の星。庚は陽、乙は陰で陰陽がちがうので、正財です。
  - q: 日干が「壬（陽の水）」の人から見て、「己（陰の土）」は？
    options: [偏財, 正財, 偏官, 正官]
    answer: 正官
    explain: 土は水をおさえる（土 → 水）ので、わたしをおさえる＝官の星。壬は陽、己は陰で陰陽がちがうので、正官です。
  - q: 日干が「乙（陰の木）」の人から見て、「癸（陰の水）」は？
    options: [偏印, 印綬, 食神, 傷官]
    answer: 偏印
    explain: 水は木を生む（水 → 木）ので、わたしを生む＝印の星。乙も癸も陰で陰陽が同じなので、偏印です。
  - q: 陰陽が「ちがう」ときに出る星の組み合わせとして、正しいものはどれ？
    options: [比肩・食神・偏財・偏官・偏印, 劫財・傷官・正財・正官・印綬, 比肩・傷官・偏財・正官・偏印, 劫財・食神・正財・偏官・印綬]

    options: [計算できなかったから, 日柱の天干は日干（わたし自身）だから, 時刻がわからないから, 天中殺だから]
    answer: 日柱の天干は日干（わたし自身）だから
    explain: 通変星は「わたしから見た相手」。日柱の天干はわたし自身なので、関係の名前がつきません。
```

## ⑧ まとめ・セルフチェック

### 3行まとめ

1. 通変星は「**日干（わたし）から見て、この漢字は何者？**」の答え。だから日柱の通変星は「—」
2. 関係は5つ（**仲間・表現・財・官・印**）。それぞれ**陰陽が同じかちがうか**で2つに分かれ、全部で10個
3. **3ステップ**（日干を確かめる → 5つの関係を決める → 陰陽で決める）で、どの命式の通変星も自分で出せる

### セルフチェック

- [ ] 「通変星は日干から見た関係」と、自分の言葉で説明できる
- [ ] 5つのグループを、まわりの人のたとえ（友だち・作品・手に入れるもの・きたえるもの・育ててくれるもの）で言える
- [ ] 「同じは、かたよる（偏）」で、10個の星の名前の分かれ方を説明できる
- [ ] 自分の命式の通変星を、アプリを見ずに3ステップで出し、答え合わせをした
- [ ] 日柱の通変星が「—」になる理由を説明できる

## ⑨ 次の章へ

通変星の「出し方」がわかりました。でも、出せるだけでは鑑定はできません。
「偏官があるから、こういう人」と言えるようになるには、**10個の星それぞれの持ち味**を知る必要があります。

次の**第12章「10の星の持ち味」**では、比肩から印綬までの10個の星を、ひとりずつ「キャラクター」として紹介します。
この章でつかんだ「わたしにとって何者か」のイメージがあれば、星の性格は覚えるのではなく、**なっとくして**頭に入ってきますよ。

## ⑩ 講師ガイド

### この回のねらい
受講者が、通変星を「暗記するもの」ではなく「日干から見た関係を、その場で出すもの」としてつかむこと。最後に、自分の命式の通変星を自分の手で出し、アプリと一致する体験をしてもらうこと。この「一致した！」という体験が、命式を読む自信の土台になる。

### 時間配分（90分の例）

| 時間 | 内容 | ポイント |
|---|---|---|
| 0:00〜0:05 | チェックイン | 「通変星、むずかしそうと思う人？」と手をあげてもらう。ほぼ全員があがる |
| 0:05〜0:20 | お話：②③ | 「わたしから見て、あなたは何者？」の質問と、5種類の人のたとえ。図を大きく映す |
| 0:20〜0:35 | ④の1〜4：しくみと3ステップ | 相生・相剋の図を手元に置かせる。「同じは、かたよる」を声に出して言う |
| 0:35〜0:50 | ④の5：ひよりさんの命式で実演 | 講師が1つ目（年柱）をやって見せ、2つ目・3つ目は受講者に答えてもらう |
| 0:50〜1:05 | 練習問題 | 基本 → 命式の順。早く終わった人は、となりの人に説明する役 |
| 1:05〜1:25 | ワーク：わたしの通変星 | アプリの通変星の段は**手でかくして**から始める。答え合わせで一致したら拍手 |
| 1:25〜1:30 | まとめ | 「わたしの命式で多かったグループ」を1人ずつ発表して、第12章への期待をつくる |

### 問いかけの例
- 「あなたのまわりで、『わたしを育ててくれた人』はだれですか？ その人は、命式でいうと何の星でしょう？」

### よくあるつまずき

| つまずき | 対応 |
|---|---|
| 相手から見た関係で考えてしまい、財と官、表現と印が逆になる | 「主語はいつも日干（わたし）」とくり返す。矢印が日干から出ているか、日干に入ってくるかを指でなぞる |
| 相剋の順番（木→土→水→火→金）があやふや | 相生の図で「1つとばし」が相剋、と第3章の図で確認する |
| 陰陽の判定でまちがえる | 十干の表で「甲丙戊庚壬が陽、乙丁己辛癸が陰」と、奇数番目・偶数番目で確認する |
| 「印綬」だけ「正印」ではない理由を気にする | 流派による呼び名のちがいで、意味は「陰陽がちがう印の星」。アプリにそろえて印綬と覚えればよい、と伝える |
| 星の意味を早く知りたがる | この章は「出し方」だけ。意味は第12章。いまは「わたしにとって何者か」のイメージだけで十分、と伝える |
