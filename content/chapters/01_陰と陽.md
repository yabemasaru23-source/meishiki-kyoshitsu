## ① この章でできるようになること

- 陰陽が「良い・悪い」ではなく、**2つで1組のペア**だと説明できる
- 陰陽の4つの約束（**良い悪いではない・ペア・くらべる相手で決まる・入れかわる**）を、身近な例で言える
- 陰陽マーク（**太極図**・たいきょくず）の、白・黒・2つの点・S字の意味を読める
- アプリの命式の「＋」「−」が陽と陰のしるしだとわかり、**自分の日干が陽か陰か**を確かめられる

## ③ たとえ話：1日は、昼と夜でできている

1日を思いうかべてください。

朝、太陽がのぼって、あたりが明るくなります。人は起きて、外へ出かけ、働いたり、話したりします。
夜になると、あたりは暗く、静かになります。人は家に帰って、体を休め、眠ります。

もし、ずっと昼だけが続いたら？　人は眠れず、へとへとになってしまいます。
もし、ずっと夜だけが続いたら？　作物は育たず、何も始まりません。

**昼と夜、どちらか片方だけでは、1日は回らない**のです。
昔の中国の人は、このように世界のあらゆるものを、**2つの組み合わせ**で見ました。明るくて動く側を**陽**（よう）、暗くて静かな側を**陰**（いん）と呼んだのです。

| 陽（よう） | 陰（いん） |
|---|---|
| ☀️ 昼 | 🌙 夜 |
| 太陽 | 月 |
| 夏 | 冬 |
| 明るい | 暗い |
| あたたかい・熱い | すずしい・冷たい |
| 動く | 休む |
| 息を吐く（外へ出す） | 息を吸う（内へとりこむ） |
| 外・表 | 内・裏 |
| 上 | 下 |
| 山の日なた | 山の日かげ |

> 💡 **「陽」と「陰」の字のなりたち**
> どちらの字にも、左に「阝（こざとへん）」がついています。これは**丘や山**をあらわす形です。
> 「陽」は、丘の**日が当たる側**。「陰」は、丘の**日かげの側**。
> 同じ1つの丘の、こちら側とあちら側。陰と陽は、もともと「1つのものの、2つの面」だったのです。

## ④ しくみ

### 1. 陰陽の4つの約束

陰陽には、覚えておきたい4つの約束があります。

| 約束 | 意味 | 身近な例 |
|---|---|---|
| ① **良い悪いではない** | 陽が良くて陰が悪い、ではない。役割がちがうだけ | 昼に働けるのは、夜にしっかり眠れたから |
| ② **ペアになっている** | 片方だけでは成り立たない。相手がいるから自分がわかる | 夜を知らなければ、「昼は明るい」とは感じられない |
| ③ **くらべる相手で決まる** | 同じものでも、何とくらべるかで陽にも陰にもなる | 夕方は、昼とくらべると陰、夜とくらべると陽 |
| ④ **入れかわる** | どちらかがいちばん強くなると、もう片方へ動きはじめる | 1年でいちばん昼が長い日（夏至）をすぎると、昼はだんだん短くなる |

> 🐱 **まあ先生**
> ③はとくに大事よ。「あの人は陽の人」「わたしは陰の人」と、1回で決めつけないこと。
> にぎやかな友だちの横では静かなあなたも、ひとりっ子の家では、いちばんよくしゃべる人かもしれないわ。
> 陰陽は**くらべて見えてくるもの**なの。

④の「入れかわる」は、呼吸を思いうかべるとわかりやすいでしょう。
息をいっぱいに吸いきったら、次は自然に吐きはじめます。吐ききったら、また吸いはじめます。
**陰と陽は、止まっているのではなく、いつも行ったり来たりしている**のです。そして、行ったり来たりしながら、全体として**バランス**をとっています。

### 2. 陰陽マーク（太極図）の読み方

陰陽の考え方を、1つの絵にしたのが**太極図**（たいきょくず）です。まあ先生のおでこにあるマークですね。
この絵には、ここまでの約束がぜんぶ入っています。

![太極図の読み方。白いところが陽、黒いところが陰。白の中の黒い点は、陽の中にも陰の種があること。黒の中の白い点は、陰の中にも陽の種があること。境目はS字で、少しずつ入れかわっていくことをあらわす](assets/img/ch01-taikyoku.svg)

| 見るところ | 意味 |
|---|---|
| 白いところ | **陽**。明るい・動く・外へ広がる |
| 黒いところ | **陰**。暗い・静か・内へまとまる |
| 白と黒で、1つの丸 | 2つで**ひとつ**。どちらが欠けても丸にならない（ペア） |
| 境目がS字 | 白が細くなるところで、黒が太くなる。**少しずつ入れかわる** |
| 白の中の黒い点 | **陽の中にも、陰の種がある**。どんなに明るい人にも、静かな面がある |
| 黒の中の白い点 | **陰の中にも、陽の種がある**。どんなに静かな人にも、燃える面がある |

> 🙋 **ひより**
> 黒の中にも、白い点がちゃんとあるんですね。
> 「陰の日干」でも、陽がゼロってわけじゃないんだ……。ちょっとホッとしました。

### 3. 人にも、陰と陽がある

人の性格やふるまいにも、陰と陽があります。どちらにも**持ち味**と、出すぎたときの**くせ**があります。

| | 陽っぽいとき | 陰っぽいとき |
|---|---|---|
| 向かう先 | 外へ。人の中へ | 内へ。自分の中へ |
| 得意なこと | 動く、話す、始める、引っぱる | 考える、聞く、続ける、支える |
| 持ち味 | 明るい、行動が早い、場をもり上げる | ていねい、思いやりがある、じっくり深める |
| 出すぎたときのくせ | せっかち、まわりが見えなくなる | ためこむ、なかなか動けない |

> 💡 **だれの中にも、両方ある**
> 太極図の2つの点のように、1人の人の中にも、陽っぽい自分と陰っぽい自分がいます。
> 仕事中は陽っぽく、家では陰っぽい。それが自然です。大事なのは、どちらかに**かたよりすぎていないか**を見ることです。

> 🐱 **まあ先生**
> 昔の本では、男の人を陽、女の人を陰と分けることもあったの。
> でも、**命式の日干の陰陽は、性別とは関係ない**わ。ひよりさん（女性）の日干「辛」は陰、そうたさん（男性）の日干「丁」も陰。女性で陽の日干の人も、たくさんいるのよ。

### 4. 命式の中の陰陽（予告）

ここからが、命式を読むためのお話です。
命式に並ぶ漢字（上の段の**天干**、下の段の**地支**）には、**1文字ずつ、陰か陽かが決まっています**。

- 天干は10文字（甲・乙・丙・丁・戊・己・庚・辛・壬・癸）。**陽・陰・陽・陰……と交互に**並んでいます
- 地支は12文字（子・丑・寅・卯・辰・巳・午・未・申・酉・戌・亥）。こちらも**陽・陰・陽・陰……と交互に**並んでいます

どの字が陽でどの字が陰かの一覧表は、**第4章（十干）と第5章（十二支）**でくわしく学びます。いまは、覚えなくて大丈夫です。
なぜなら、**アプリが「＋」「−」のしるしで教えてくれる**からです。

| アプリのしるし | 意味 |
|---|---|
| **＋** | 陽 |
| **−** | 陰 |

アプリの命式タブでは、「干支」の段の大きな2文字の**上と下に、小さな字**が出ています。
上の小さな字が**天干の陰陽と五行**、下の小さな字が**地支の陰陽と五行**（と、十二支の読み方）です。

ひよりさんの命式では、こうなっています。

<div class="meishiki-box">

| | 時柱 | 日柱 | 月柱 | 年柱 |
|---|---|---|---|---|
| 上の小さな字（天干） | −木 | **−金** | −火 | ＋土 |
| 干支（大きな2文字） | 乙未 | **辛**酉 | 丁巳 | 戊寅 |
| 下の小さな字（地支） | −土 ・ ひつじ | −金 ・ とり | −火 ・ み | ＋木 ・ とら |

</div>

日柱の上の小さな字は「**−金**」。つまり、ひよりさんの日干「辛」は、**陰の金**です。
アプリの五行タブに出ていた「陰の金」と、ちゃんと同じですね。

> 💡 **陰陽の「数」で、性格を決めつけない**
> ひよりさんの8文字のうち、＋（陽）は年柱の「戊」と「寅」の2つだけで、ほかの6つは−（陰）です。
> でも、「陰が多いから暗い人」とは読みません。陰陽は良い悪いではなく、**くらべる相手で決まる**ものでしたね。
> 命式を読むときは、まず**日干の陰陽**を見ます。日干の陰陽は、第11章で学ぶ通変星を出すときにも使う、大事なカギになります。

> 🐱 **まあ先生**
> 陰の金の「辛」は、たとえるなら、みがかれた**宝石**や**アクセサリー**のような金。大きな刀のような陽の金「庚」とくらべると、小さく、繊細で、キラリと光る金なの。
> 同じ金でも、陽と陰で持ち味がちがう。これが第4章の「10人の主人公」のお話につながっていくわ。

## ⑤ アプリで見てみよう

> 📱 **アプリで見てみよう：命式タブと五行タブ**
> 1. [命式アプリ](https://qmw.co.jp/meishiki/)で自分の命式を出し、「**命　式**」タブを開きます
> 2. 「**干支**」の段を見ます。大きな2文字の**上と下に、小さな字**（「＋土」「−金 ・ とり」など）が出ています
> 3. **日柱の、大きな2文字の上の小さな字**を見てください。「＋」なら日干は**陽**、「−」なら**陰**です。そのあとの漢字（木・火・土・金・水）が日干の五行です
> 4. ほかの柱の小さな字も見て、＋と−がいくつずつあるか数えてみましょう（時刻が不明の人は6文字、わかる人は8文字）
> 5. 「**五　行**」タブを開き、棒グラフの下の文章の最初を見ます。「日干は〇（陰の〇）。」のように書かれていて、3で見た陰陽と同じになっていれば確認完了です

## ⑩ 講師ガイド

### この回のねらい
受講者が、陰陽を「良い・悪い」ではなく「ペア・くらべる相手で決まる・入れかわる」ものとしてつかむこと。とくに、自分の日干が「陰」だった人が、それを**マイナスの意味に受けとらない**ようにすること。最後に、アプリの＋・−で自分の日干の陰陽を確かめて帰ってもらう。

### 時間配分（45分の例）

| 時間 | 内容 | ポイント |
|---|---|---|
| 0:00〜0:05 | チェックイン | 「あなたは自分を、陽っぽい？ 陰っぽい？」を直感で手をあげてもらう。答えはあとでひっくり返す |
| 0:05〜0:12 | お話：②③ | まあ先生の顔の白と黒で笑いをとる。昼と夜のたとえ、陰陽のペア表 |
| 0:12〜0:22 | ④の1〜2：4つの約束と太極図 | 太極図を大きく映し、白の中の黒い点・黒の中の白い点を指さす。「くらべる相手で決まる」で、チェックインの手のあげ方を見直す |
| 0:22〜0:30 | ④の4と⑤：アプリで＋・− | 全員で命式タブを開き、日柱の上の小さな字を確認。五行タブの文章とも見くらべる |
| 0:30〜0:35 | 練習問題 | ひとりで解く → 答え合わせ |
| 0:35〜0:43 | ノート：陰陽リストと、陽っぽい・陰っぽいわたし | 2人組で、おたがいの「陽っぽい場面・陰っぽい場面」を聞き合う |
| 0:43〜0:45 | まとめ | 「わたしの中の陰の種・陽の種」を1人ひとこと |

### 問いかけの例
- 「最初に『陰っぽい』に手をあげた人。陽っぽくなる場面は、本当にひとつもありませんか？」
- 「夜がなかったら、昼はどうなると思いますか？」
- 「同じ人が、ある場所では陽、別の場所では陰になる。あなたにも、そんな場所の組み合わせはありますか？」

### よくあるつまずき

| つまずき | 対応 |
|---|---|
| 「陰＝暗い・悪い・運が悪い」と受けとって、陰の日干の人が落ちこむ | まあ先生の顔の半分を指して「先生の半分は悪者？」と問いかける。太極図の「黒の中の白い点」を見せる |
| 陰陽を性別と結びつけてしまう（女性だから陰、など） | 命式の日干の陰陽は性別と関係ないと伝える。ひよりさん（女性・陰）、そうたさん（男性・陰）の例を出す |
| 「自分は陽の人／陰の人」と1つに決めたがる | 約束③「くらべる相手で決まる」にもどる。場面によって入れかわるのが自然だと伝える |
| アプリの小さな字を見落とす、または上と下を取りちがえる | 「大きな2文字の上の小さな字が天干、下が地支」。日干の陰陽は**日柱の上**と、指でさしてもらう |
| ＋・−の数を数えて、性格を決めつけようとする | 数で決めつけず、まず日干の陰陽を見ると伝える。陰陽は「くらべる相手で決まる」ことにもどる |
| 十干・十二支のどれが陽でどれが陰か、覚えようとする | いまは覚えなくてよい。アプリの＋・−で確かめられる。一覧表は第4章・第5章で |
